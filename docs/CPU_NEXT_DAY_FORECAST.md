## 如何使用

1. 打开个股的真实日K，进入右侧“次日预测”。默认不创建图表选区，不随行情刷新自动训练。
2. 选择“盘后预测下一交易日”或“14:35预测下一交易日”，选择基准日D，点击“预测下一交易日”。下一天按已核对的2025／2026沪深交易日历确定。
3. “展开回测与模型参数”可设置回测起始D、目标严格早于的日期、相似日数量及排除日期；“历史逐日验证”对价格、量价、多因子三组作对照。排除日期以逗号分隔。
4. 输出方向或“暂不判断”、相似日OHLC变化分布、次日开收关系、候选支撑压力、成交分布代理与模型贡献。“取消”可终止后台进程；切股、改参数会取消旧任务，旧结果不会覆盖新证券。
5. 可导出JSON、Markdown及逐条CSV。预测与评价先后写入本地`forecast.sqlite`，旧0.3 H1／H2档案保留；新记录有独立模式、目标、模型和特征版本。

桌面只读取已有本地分钟和沪深300缓存作为辅助输入，不因点击预测自动下载数百天数据。股票日K来自当前图表；缺少长期分钟数据时，14:35明确显示输入不足或训练不足。可通过已有行情补数流程积累缓存，或者用CLI提供完整真实分钟档案。指数暂不作为预测对象。

```bash
# 已保存的日线输入；CLI无桌面和GPU依赖
python -m chengchuan.nextday predict --dataset daily.json --as-of 2026-11-05 --mode close
python -m chengchuan.nextday backtest --dataset daily.json --start 2026-01-05 --before 2026-11-06
python -m chengchuan.nextday predict --dataset daily.json --minute-dataset min1.json --as-of 2026-11-05 --mode cut1435
```

输入使用现有`research_input_version=1`档案。分钟快照必须为`interval=min1`、真实OHLC；分时采样、5分钟K不能代替。CLI不会隐式使用本机辅助缓存，因此需要将基准指数保存在日线输入的`benchmark`字段，才能与桌面使用相同市场背景。

## 特征与模型

共63项固定特征，先要求此前60个市场交易日连续有效。当前不将财报、当前股东、热度、概念成员名单或事后新闻回填到历史D；这些数据缺少可靠历史可得时点，暂不进入预测。

| 特征族 | 实现 | 含义与限制 |
|---|---|---|
| 价格与技术 | 1／2／5／10／20／60日收益、均线距离与斜率、简单RSI14、MACD、ATR14、波动率、布林位置／宽度、跳空、实体、影线 | 均从截止点历史计算；不是买卖规则 |
| 成交量 | 较前1／2／5／20日均量、量能趋势、历史涨跌日成交量差及量价交互 | 14:35量比使用同钟累计量，缺失不以全天量代替 |
| 支撑压力 | 此前20／60日高低点、ATR归一化距离、触及次数、突破／突破回落 | 是历史结构候选，不保证产生支撑或反转 |
| 筹码代理 | 60日成交量价格分布、代理成本／峰值、价格下方成交权重、上方5%区间权重、集中度及宽度 | 日K区间均匀分配到40个价格格，20交易日半衰期；没有真实持仓、账户或换手留存模型 |
| 行为代理 | 连涨跌长度、10日上涨比例、下影承接／上影衰竭、回撤与反弹 | 描述价量现象，不声称读懂真实投资者心理或识别机构 |
| 市场背景 | 沪深300收益、相对强弱、20日相关性及beta | 对齐历史日期；14:35只用D−1及更早日线，不用指数D的最终行情 |
| 盘中结构 | 截止时点的价格、波动、量价结构 | 只在具备真实分钟覆盖时提供，不能由日线推造 |

模型固定为50%分族等权KNN、40%L2正则逻辑回归、10%训练类别频率。默认21个近邻、至少60个成熟样本、最多最近240个成熟样本；逻辑回归48步，正则强度0.12。预处理仅拟合传入的成熟训练样本；中位数填补和稳健缩放不读取未来标签。缺失、训练覆盖不足或常数特征被排除；KNN各特征族等权，避免堆积大量同类指标自动增加其总权重。

融合领先差不超过0.08，或KNN与线性方向明显冲突时拒判；评分是内部诊断值，`calibrated_probabilities`始终为空。线性贡献只解释该模型的方向，不是因果，也不是整套融合模型的完整归因。

## 预测目标与时点边界

- 两种模式均预测下一交易日收盘相对D最终收盘的涨／平／跌，平指严格零变化。不是14:35买入后的收益目标。
- 盘后D完成时点按15:15处理。当日必须有来源取得时间至少15:15、报价至少15:00，且都不晚于执行时间；日线名义15:00时间戳本身不能证明完成。
- 14:35完全排除D最终日线，只从真实1分钟OHLC生成部分日K。保守使用标时早于14:35且标时加1分钟不晚于截止点的记录，对起点／终点标时均不纳入可能越界的整根14:35分钟。
- 14:35要求D及此前5个交易日的共同分钟网格完整（09:31—11:29、13:01—14:34，边界分钟可额外存在）；缺失不填。RV20需此前20日同钟覆盖，否则该特征留空。该规则保守，也可能拒绝真实无成交分钟缺省的来源。
- D 14:35不使用依赖D收盘的训练标签。每个训练标签的`available_at=目标日15:15`必须不晚于该次预测截止；收盘价、全日量不会从标签侧进入当日盘中特征。
- 分钟历史通常只有事件标时及事后查询时间，没有逐条接收时间，故明确标为“历史重建”，尚不能声称复现实时收到的信息。没有数据就不以盘后模型替代。

“走势”输出为近邻次日开／高／低／收相对D收盘的P10／P50／P90百分比，以及“高开收低于开盘／低开收高于开盘／收高于开盘／收低于开盘／收盘接近开盘”计数。开收形态阈值固定0.3%，按OHLC关系分类，不推断最高与最低发生的顺序。形态计数并列时，评价沿用固定名称排序取首项；完整计数始终保留。14:35不知道D最终收盘，不能将这些百分比乘以14:35价格当作次日绝对价格。经验分位数也不是校准后的80%保证区间。

价格目前不复权，除权除息会影响输入和标签。排除日期仅排除该日发出的预测和跨该日的标签，**不会自动修复之后60日特征中的价格断点**；系统公司行为调整仍未完成。本版结果属于原始价格诊断。

## 历史验证与真实结果

先冻结证券、日期、参数及源码SHA-256，逐日D只使用当时已成熟的标签训练，再保存所有预测，最后揭晓真实结果。目标日期严格小于评估上界；停牌或缺失目标不顺延、不填零。保存实际使用的日线／基准指数和分钟快照，源缓存改变后仍能追溯输入。

报告分别显示有效方向数、命中率、全猜涨／历史多数类／延续今日方向基线、输入／预测／标签覆盖、三组共同样本、月度表现、类别覆盖、OHLC分位区间实际覆盖与误差、形态命中。总体与各类的拒判都会披露；`selective_balanced_accuracy`只代表已判断子集，同时报告把拒判计为未命中的召回。探索性误差区间用五个基准日的连续块重采样300次，保留未预测位置；不能视为跨股票的正式统计证明。

## 工程实现与验收

- `domain/nextday.py`：独立输入、预测、评价与配置契约。
- `application/nextday_features.py`、`domain/nextday_model.py`：特征与无I/O的CPU模型。
- `application/nextday.py`：时点隔离、标签成熟、逐日滚动及先预测后评价。
- `application/nextday_metrics.py`：同样本基线、拒判覆盖及情景误差。
- `infrastructure/nextday_inputs.py`：已存分钟及沪深300缓存，只读查询，不取密钥、不发HTTP。
- `ui/nextday_panel.py`：复用现有任务、取消及导出框架；300秒硬超时，无行情刷新重复训练。
- `scripts/check_nextday_research.py`：真实离线冻结实验；`scripts/check_nextday_workbench.py`：强制offscreen的真实GUI工作流验收。

本轮完整源码测试370项通过（58.399秒，其中新增46项）；隔离安装wheel后，无Qt环境执行267项核心测试通过，103项桌面测试跳过。真实GUI全程offscreen，单次久立预测约1.2秒，完成逐日回测／导出／取消与切换，并检查1100×740参数滚动区域。构建产物为`dist/chengchuan-0.16.0-py3-none-any.whl`，不含密钥或本地行情缓存。

测试覆盖未来日线／晚于14:35分钟篡改不影响预测、D收盘训练标签隔离、模式档案不覆盖、输入缺失、目标不顺延、基线同样本、类别拒判、真实后台进程、取消／切换、导出和小窗口。合成数据测试仅证明代码行为，不算市场预测准确率。没有模拟交易收益；方向命中也不包含可成交性、涨跌停、滑点和成本。

后续应先补可靠公司行为及长期分钟历史，再扩展预先指定的股票和市场环境、建立新封存期及真正前瞻记录；只有在这些条件下取得稳定增量，才考虑公开校准概率。更多特征、Level-2或GPU本身不构成有效性的证据。
