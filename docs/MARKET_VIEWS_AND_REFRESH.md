# 0.8：刷新、热力图与资金分类

日期：2026-11-04。版本：0.8.0。预测增强继续P2后置。

## 无闪动刷新

同证券、同周期刷新时保留原图和多行行情状态，在底部提示正在刷新。以前将多行来源信息临时换成一行，会改变图表高度；返回后清空并重建图元，又会造成跳动。现在原位更新K线绘图缓存、分时曲线、均价线和成交量柱，保留缩放、选区、十字线和定位标记；完整行情指标也不再退回基础字段后重建。变化行情仍正常修改价格、量柱和纵轴。

## 自动检查与闭市补齐

设置中的15秒是**本地调度检查间隔**。闭市缓存已经齐全就不启动后台行情查询，不等于每15秒发HTTP。

| 场景 | 自动行为 |
|---|---|
| 交易日09:15—11:30、13:00—15:30更新窗口 | 按设置间隔检查，包含竞价与盘后量额更新；付费源仍至少180秒复用 |
| 午休 | 11:33后确认上午数据，齐全即暂停查询 |
| 盘后 | 15:45后确认当日数据，齐全即暂停查询 |
| 盘前、周末、节假日 | 比较最近已结束的交易日；缺失、落后或只有盘中值时允许补取 |
| 历史日期、本地快照、离线、关闭自动检查 | 不自动拉取 |
| 日历未覆盖年份 | 提示更新日历并暂停自动判断；F5仍可使用 |

11:33和15:45是本应用的发布缓冲，**不是交易所交易时间**。普通分钟图仍截至15:00，没有新增盘后固定价格分钟图；盘后固定价格交易可能更新当日量额。参考[上交所2026年规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)和[深交所2026年规则](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)。

图表、行情详情、六指数摘要及当前打开的资金页分别判断。最近下载但日期落后、日K名义15:00标签、分钟缺少时段末尾、某个组成接口仍是旧响应，均不能当作全部最新。未打开资金页不额外轮询；热力图按需加载和手动刷新。

闭市最多补取4轮：立即一次，再间隔3、5、15分钟。接口未发布、无权限、停牌或持续缺失时不整晚反复请求；保留原数据和原时间，提示F5。切上下文、下一交易阶段或明确手动操作可重新判断，仍不绕过源缓存、限流和额度。日历只覆盖已核对的2025／2026年，周末补班不会当交易日。旧v1指标缓存缺少全部组成响应的确认语义，读取后视为待确认。

源响应仍是旧交易日或分钟缺收盘时，不套用盘后长期缓存；至少180秒后允许再次补取，避免“下载很新、内容落后”的响应冻结一整天。

## 热力图

点击顶部“市场热力图”，选择行业板块、概念板块或沪深个股。行业／概念分别来自`theme_daily(type=hy/gn)`；个股复用指数市场统计的同日`screening`，增加成交额字段，排除当前不支持打开的市场。

面积表示所示标的的源成交额，红涨绿跌，缺失涨跌幅用灰色；成交额无效或为零不分配面积，不补造等权面积。默认成交额前200项，可改100／500。名称或代码筛选在本地完成，不请求API；个股可按打开时的自选名单筛选，点击个股切主图。

板块可能有层级和成分交叠，面积不代表互斥的全市场份额。状态显示源记录数、筛选数、绘制数、日期和取得时间。达到6000条截断边界、混入不同日期或类型时拒绝冒充完整数据。

布局独立于Qt，最多500个区域，只在数据或尺寸变化时重算；鼠标移动只命中已有矩形，不调用网络或创建大量子控件。关闭热力图、退出主窗口或切源会取消任务。当前仅最新快照，历史热力图与行业层级筛选待接入。契约：[板块日线](https://meoz.cn/docs/query/theme/daily)、[实时选股](https://meoz.cn/docs/query/stock/screening)。

## 主力与散户参考资金

右侧“资金”页可选**当前证券**或**沪深大盘**，显示主力、散户参考、超大单、大单、中单、小单的流入、流出和净额；支持个股及六指数。

猫爪`fundflow_kp`提供主力买卖与净额，没有小单，原行情卡片保留。新资金页整表使用**东方财富公开资金分类**，不混用来源：

- 主力＝大单＋超大单，分别相加流入／流出，净额保留源主力净额。
- 散户参考＝中单＋小单，是成交规模代理指标，不代表识别到真实散户账户。
- 沪深大盘＝来源上证、深证对应范围相加，两个响应必须证券匹配、日期相同；时点显示较早者。
- 指数是供应商关联范围，尚未独立复核历史成分名单；不与猫爪沪深／板块统计混算。

字段及元单位按[东方财富个股资金页](https://data.eastmoney.com/zjlx/002318.html)和[官方前端请求与绘图代码](https://data.eastmoney.com/newstatic/js/zjlx/stock.js)核对。使用`api/qt/ulist.np/get`资金字段组，不能挪用`stock/get`中的同名数字字段。校验证券、交易所及真实时点，缺失显示“—”、真实零保留零。源净额与买卖汇总可能有舍入差。

公开源无需猫爪密钥，不消耗猫爪高频接口额度；不可用时保留旧快照和原时间，不换口径拼算。资金页按需加载并缓存，切证券／范围会拦截迟到结果。历史资金尚未接入，历史日期浏览时明确提示。

## 体验版与后续高频模式

本版仍强制**体验保护**：每接口95次／日、总计90000次，付费源至少180秒复用；失败与中断计入预留。本轮只做少量联网验证，后续离线回放。

用户计划购买990元／年专业版。[官方套餐页](https://meoz.cn/pricing)目前列明专业版无体验版每高频接口100次日限额，但全账号仍为10次／秒、每日10万次，各接口还可能有自己的频率和发布周期。

**专业版高速链路尚未启用**，不会因未来购买意向取消当前保护。后续P1实施应分离套餐策略、传输、缓存和UI节流：按实际权益设置全账号及接口预算；获权且支持时优先订阅推送，设计持续连接和重连；报价、曲线复用图元并按帧合并，分钟、估值和资金按各自发布频率取数；用持久工作通道替换逐次创建进程。先用录制数据压力测试，账户升级后再做少量实际核验。预测和Level-2模型继续P2。
