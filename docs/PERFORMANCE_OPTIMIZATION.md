# 0.15性能优化与复验

日期：2026-11-06。覆盖行情切换、公共后台任务、缓存存储、图表绘制、公司资料、市场研究、搜索、热力图与逐笔工作台。保留现有Python／Qt架构与来源、时间、单位口径，预测增强仍为P2。

## 使用变化

- **先出图，再检查更新**：优先复用当前会话的行情；会话没有时，在后台线程读取已有本地缓存，与行情更新同时进行。新股票立即清除上一只的内容，只显示身份匹配的数据。旧数据保留原日期及取得时间，明确提示后台更新，不改成当前时间。
- **切周期复用已有数据**：日线可转周／月／季／年K，真实1分钟OHLC可转较大分钟K，五日可提取末日分时。证券、来源、日期独立，不用采样分时编造OHLC，不把单日分时当完整五日。已加载的图中历史仍按0.14.1方式保留。
- **详情不挡图表**：先显示图表及基本行情，再异步补充详情指标；同一股票与日期的详情不因切周期反复请求。F5及明确更新操作继续绕过会话复用，后台缓存和额度规则仍生效。
- **其他页面少做重复工作**：公司资料、研究模块、板块成份、热力图、搜索都有有界短期缓存；完整性不足的数据不作为完整资料复用。重复打开相同逐笔分析不重建原单表，隐藏的扩展窗口在打开时更新。

首次没有任何本地数据的股票仍需等待接口返回。上述优化降低本地开销和等待感，不承诺消除供应商网络延迟，也不提高原数据更新频率。

## 工程调整

| 环节 | 实现与边界 |
|---|---|
| 公共后台任务 | 同一执行器复用spawn进程及已导入模块；每32项任务轮换，空闲10秒回收。运行中替换、超时和关闭仍可终止；仅运行中以16毫秒轮询结果，空闲不轮询 |
| 私有SQLite | 已初始化的猫爪原始缓存和研究档案不再每次连接重写建表／版本语句；首次初始化和旧档案迁移保留，独立连接、WAL、事务、额度预留及大小上限保留 |
| 行情编解码与内容摘要 | 标量字段直接构造载荷，避免递归深拷贝全部行情；原JSON及哈希口径保持一致并有兼容性测试 |
| K线 | 分块从128根起，大图自适应增大块以控制总块数不超过64，避免缩到全图时反复淘汰、重画。仅绘制可见块，更新只使变化块失效。量柱只提交可见范围及两侧各80条预留；分时曲线按视口裁剪，底层数值与可选记录完整保留 |
| 表格 | 数据、排序或本地过滤未变时不重复重置／排序；保留当前选择，不为每个单元格建立控件 |
| 取消 | 快速切股／日期／来源、导入快照、关闭及迟到结果继续按请求代次隔离。缓存预览只读本地存储，不读密钥或请求HTTP |

会话缓存按数据量和条目数同时设上限：

| 数据 | 上限 | 复用规则 |
|---|---|---|
| 行情帧 | 48项／12万条记录 | 每次按原取得时间、数据日、来源TTL与历史条件判断是否后台更新 |
| 行情详情 | 80项 | 按股票／日期；完整与部分数据分别判断时效 |
| 公司资料 | 24组／24万单元格 | 完整结果60秒；“联网更新”绕过会话缓存 |
| 特色研究 | 16组／24万单元格 | 完整结果30秒；查询更新绕过会话缓存 |
| 热力图与板块成份 | 24组／4万标的 | 完整结果30秒，含热力图窗口重开；手动更新绕过 |
| 搜索 | 64个关键词／2000条证券结果 | 60秒，切源清空 |

切换数据源清理该窗口会话缓存；重复读取不会延长原缓存时效。价格显示窗口、后台统计数据和正式原始缓存分别管理，不将多日扩展或本地转换覆盖为普通单日源响应。

## 性能测量

环境：Intel i7-13620H、Ubuntu 22.04.5、Python 3.10.12、PySide6 6.11.3、pyqtgraph 0.14.0，1600×1000离屏窗口。比较0.14.1提交`1c6fbb4`和0.15，同一台机器、同一套真实本地数据、相同21条操作序列，均为2026-11-04日期范围。旧版在独立只读基线工作树运行，两版各执行3轮，包路径分别核验。

操作覆盖久立全部12周期、宁德时代日K、六个A股指数日K及上证指数分时／五日。先准备两版本相同的磁盘缓存，再创建新的窗口；“首次”指新窗口第一次进入该视图，“重复”指随后再次切回。时间从调用切换到目标数据已渲染且价格视口收到Paint事件，不是单纯计时函数返回。后台指标完成另行记录；首图不等待这些指标。

| 场景 | 样本 | 0.14.1中位 | 0.15中位 | 0.14.1 P95 | 0.15 P95 |
|---|---:|---:|---:|---:|---:|
| 新窗口首次进入已有本地缓存的视图 | 21 | 356.23毫秒 | 46.14毫秒 | 422.74毫秒 | 79.57毫秒 |
| 同一窗口再次切回 | 42 | 352.34毫秒 | 30.98毫秒 | 421.50毫秒 | 46.16毫秒 |

中位耗时分别降低约**87%／91%**。两版63条测量的证券、周期、轮次及记录数逐条一致，均无跳过案例，新增API请求为0。逐项首图与全部指标就绪耗时见[CSV记录](performance/navigation-0.15.csv)。

样本仅代表本机、有缓存的交互。真正无缓存的网络首载、Windows原生操作、长时间开市高频压力和10万条行情不在本次速度承诺内。
