# 量价位置与阶段联合预测：功能规划

日期：2026-11-03。状态：**仅规划，未实现、未训练、未回测，预测概率尚未启用**。

基于本地`421b518`提交的0.2行情工作台编写；该版本的股票搜索、自选、行情刷新、缓存与Qt稳定性修复继续保留。本轮只修改文档，不调整代码、依赖、数据库或软件版本。

关联：[产品规划](PRODUCT.md)、[功能路线](ROADMAP.md)、[工程架构](ARCHITECTURE.md)、[UI规范](UI_DESIGN.md)、[历史逐日验证方案](FORECAST_VALIDATION.md)。

## 1. 用户需求与研究目标

联合研究以下信息，判断未来一个、两个交易日的价格变化是否更可能延续或反转：

- 今天相对昨天、前两天及较长基线的放量／缩量。
- 今天处于近期高位、低位、突破或跌破位置。
- 今天上涨、下跌、滞涨、盘中回收及收盘强弱。
- 固定历史窗口内的承接／疑似吸筹、趋势上行、卖压／疑似派发、回撤承接／洗盘候选评分。
- 同期大盘、行业及事件环境，按数据实际覆盖逐步加入。

目标是验证这些特征的**增量预测价值**，不预设联合模型一定优于现有模型，也不以预测结果证明机构身份或交易动机。

第一阶段使用公开日线即可研究，不以Level-2采购为前提。先完成收盘版；盘中同时间比较另行实施。这里的“明日”均指交易所日历中的下一个交易日。

## 2. 当前能力与前置缺口

| 项目 | 0.2现状 | 对本功能的影响 |
|---|---|---|
| 在线日K | 腾讯公开源，当前请求最近320条，不复权，含OHLC及成交量 | 可作为基础特征输入；不等于已有多年全市场训练库 |
| 最新一根日K | 盘中仍变化；记录时间统一写为当日15:00 | 不能只凭时间戳判断已收盘或数据已最终确认 |
| 成交额、VWAP | 在线日K源缺失 | 基础版不依赖；不可用收盘价乘成交量补造 |
| 基准、板块及订单分类 | 在线快照尚未获取 | 分开规划数据补齐和模型版本，不能从旧股票快照拼入 |
| 分钟行情 | 近期分钟末采样价与量额，不是真实分钟OHLC | 同时刻量比较需检查历史覆盖和累计值；不补造盘中高低价 |
| 行情缓存 | 每个股票／周期保留最新帧，最多200组 | 不能作为不可变研究档案，需独立历史保存机制 |
| 阶段判断 | 旧引擎透明规则，已使用部分量价特征 | 只能作为未校准候选特征；须验证重复信息问题 |
| 数据时间 | 报价时间、图表覆盖、取得时间已分开 | 可复用，但还需明确预测截止时点及日K完成状态 |

开始历史验证前，需要可复现的数据快照、足够历史跨度、交易日历和公司行为处理。当前的“可画图”不自动意味着“符合预测样本要求”。

## 3. 预测时点与目标定义

### 3.1 收盘版优先

以交易日`t`已完成的日K为输入，使用截至固定截止时点可获得的信息产生记录。预测输入至少记录：交易日、北京时间截止时点、数据取得时间、源数据版本和完成状态。

日K完成确认需要交易日历、源数据状态及收盘后核对规则。当前字段中的15:00仅是记录标识；收盘时钟已到、HTTP刚刚成功或报价刚刚刷新，都不能单独证明日K已最终完成。收盘确认及源数据更正规则在实施前固定，修订记录保留新版本，不回写旧预测。

至少有当日和此前60条有效日线，才能形成完整20／60日位置特征。历史不足时返回缺失原因与实际样本数，不把短窗口冒充完整窗口。

### 3.2 两个独立目标

设`C_t`为交易日`t`按一致价格／公司行为口径处理的收盘价：

| 目标 | 定义 | 含义 |
|---|---|---|
| H1 | `C_(t+1) / C_t - 1` | 下一个交易日收盘相对今天收盘的变化 |
| H2 | `C_(t+2) / C_t - 1` | 两个交易日后收盘相对今天收盘的累计变化 |

H2不等于第二天单日涨跌，也不等于未来两天每天都上涨。若以后研究这些事件，分别增加目标版本，不能混用统计。

主口径分别统计正收益、零收益、负收益；概率启用后，其三类概率应归一。小涨小跌的中性区间可作为独立实验，但阈值只能在训练／验证阶段确定，不能事后改标签以美化命中率。

未来目标未成熟时不填标签。预测目标日期按市场交易日历确定；目标日个股停牌或没有有效收盘价时标记不可用，不自动顺延到下一条有成交记录，也不填零收益。

### 3.3 盘中版后置

盘中比较使用相同北京时间的历史累计量。例如今天14:00累计成交量，应与过去交易日截至14:00的累计量比较，不能与过去全天量直接相除。

盘中样本必须固定截止时刻，排除之后才产生的最高最低价、收盘价和全天量。午休、缺分钟、停牌及提前中断交易的样本分别处理。当前只有近期分钟数据，不足以验证跨市场环境的盘中预测。

## 4. 候选特征与口径

以下均为计划中的特征，不代表已经写入现有引擎。

### 4.1 相对成交量

设`V_t`为完整交易日成交量，单位股；比较基线排除当天：

| 特征 | 定义／用途 |
|---|---|
| RV1 | `V_t / V_(t-1)`，较昨日成交量 |
| RV2 | `V_t / mean(V_(t-1), V_(t-2))`，较前两交易日平均量 |
| RV5、RV20 | 较此前5日、20日平均量，避免昨日异常量扭曲解释 |
| 连续量价序列 | 最近2—3日量的扩张／收缩和涨跌排列，不仅看单日比值 |
| 异常量位置 | 在此前有效历史中的成交量分位，阈值在训练阶段冻结 |
| 换手率相关 | 有当时流通股本历史时再加入；不能用当前股本回填所有历史 |

界面明确写“较昨量”“较前2日均量”，不默认等同于其他软件的内置量比口径。分母为零、比较日停牌或样本不足时，值为空并附原因；不把除零结果变成极大放量。

### 4.2 多周期价格位置

分别计算20日、60日位置。参考定义：以此前N日真实最高价的最大值和最低价的最小值为区间，用今天收盘价确定相对位置。基线排除当天，全部信息截至当时可知。

位置值允许大于1或小于0，用于保留突破／跌破信息，不强行截断。区间高低点相同则返回缺失。另记录距前高、前低距离、近期涨跌和从前高回撤，区分“跌了很久的低位”和“上升趋势内的短期低位”。

高位、低位和显著放缩量的分组阈值属于研究参数，须记录版本；不得在看过测试集结果后反复更改。

### 4.3 当日收盘结构

- 相对昨收涨跌、开盘缺口及开盘到收盘的变化，分别保存。
- 收盘在真实当日高低价区间的位置、上影线、下影线、实体与振幅。
- 当日高低价相同时标记无有效区间，不把中点当作观测结果。
- 放量而价格推进有限、下跌后收回等量价交互特征。
- 有合法有效成交额时才使用VWAP与成交额特征；基础版本允许这些字段缺失。

### 4.4 阶段特征与市场环境

阶段输入采用预先固定的回看窗口，例如近5日、20日的完整评分向量、支持证据和缺失标记；窗口是实验配置，不由事后任意框选决定。当前规则分数不能直接当作预测概率。

阶段评分本身包含涨跌、量比、收盘位置等信息。联合模型须检验额外作用，不能简单给同一事实重复加分。未来若阶段模型也需要训练，训练预测模型时须使用符合当时信息集的阶段输出，不能使用在测试期训练过的阶段模型。

市场特征包括同期大盘、行业相对涨跌、波动和活跃度。公告、业绩等信息只有取得准确发布时间后才能加入。市场数据缺失时使用事先定义的基础版本或拒绝相应预测，不从未来或其他股票补齐。

## 5. 待检验组合假设

| 当日结构与价格位置 | 阶段候选 | 待检验方向 | 需要区分的竞争解释 |
|---|---|---|---|
| 低位放量上涨、收盘较强 | 承接／转强 | 上涨延续 | 下跌趋势中的反抽 |
| 低位放量下跌、尾盘收回 | 承接候选 | 短期反转 | 利空尚未充分反映 |
| 低位放量下跌、收于低位 | 卖压／派发 | 下跌延续 | 恐慌交易后的均值回归 |
| 高位放量突破、上影线短 | 趋势上行 | 上涨延续 | 一次性事件驱动的冲高 |
| 高位放量滞涨或长上影回落 | 卖压／派发 | 短期回落 | 强势换手后继续突破 |
| 上升趋势中缩量回撤、关键位置未破 | 回撤承接／洗盘候选 | 恢复上涨 | 需求衰退形成的趋势转弱 |

这些是研究问题，不是已验证交易规则。不能在未来两天上涨后，反过来将当天标为“洗盘”并放入当天预测输入。

## 6. 增量验证与模型对照

在同一数据、相同时间切分、相当调参预算下比较：

| 实验 | 输入 | 检验目的 |
|---|---|---|
| A：价格基线 | 价格位置、近期涨跌、收盘结构及可用市场环境 | 建立不依赖成交量的对照 |
| B：量价联合 | A加相对量、量序列及量价交互 | 成交量是否增加预测信息 |
| C：阶段融合 | B加固定窗口阶段评分向量 | 阶段结果是否仍有额外价值 |

先用简单、可解释的分类／收益估计基线，数据足够后再评估非线性模型。具体算法库及依赖留待实施时决定，本轮不新增依赖。不得直接将规则分数归一化后命名为上涨概率。

需要同时报告公共有效样本上的公平对照和各版本实际覆盖率，避免因为过滤了难预测样本而产生虚假提升。C没有稳定增益时，可以只保留通过验证的B；没有模型通过时保留特征研究功能。

## 7. 历史数据与防止未来信息

执行流程详见[历史逐日验证方案](FORECAST_VALIDATION.md)：对每个D先锁定截至当日的输入与方法，
保存预测后再揭晓D+1／D+2，连续滚动并与简单基线对照；另设封存测试期和后续前瞻记录。

- 可先用已有约320条日线做流程核对和小规模样本外评估，明确扣除回看、训练与验证后的测试样本数；随后扩展多股票、多年、跨市场环境，不能用单股小样本证明普适准确率。
- 按时间滚动划分训练、校准／验证和独立测试区间；同一交易日期的不同股票保持同组，不能随机打散相邻日期。
- 两日目标的标签在分界处至少按两交易日跨度清理，确保训练或校准时没有使用下一分区才成熟的标签。历史特征的正常回看不等于允许使用未来标签。
- 调参及校准不接触最终测试结果，保留实验次数和模型选择记录。
- 股票样本与行业归属尽量使用当时可知状态，记录退市、停牌、新上市、ST及涨跌停等覆盖；不能只选今天仍上市的赢家。
- 价格和成交量分别处理公司行为影响，调整方法、可获得时点及版本可追溯。当前不复权日K跨除权区间不能直接当作真实收益标签。
- 当前阶段规则和未来模型都须在历史截止点重算，不能从全样本事后标签库直接读取当天结论。
- 收盘版与不同盘中截止时刻分别建立数据集和评估，避免把全天信息用于盘中预测。
- 将数据修订、缺失、停牌与标签不可用的原因记录下来，不静默删除不利样本。

## 8. 评估指标与概率启用门槛

H1、H2分别报告有效样本数、覆盖率、实际正／零／负收益比例，以及简单基线和A/B/C模型结果。

方向命中率、看涨／看跌信号准确率、输入合格率、预测覆盖率和标签可评价率分别统计；
不预测或失败不能当作正确，也不能无痕删除。逐条账本与指标分母见[验证方案](FORECAST_VALIDATION.md)。

主概率指标采用Brier分数，辅助观察对数损失和校准情况；同时报告方向命中率、平均及中位收益、下行尾部和不同年份／市场环境表现。不能只比较是否超过50%命中率。

按日期分块评估误差，考虑两日收益重叠和股票共同市场波动。报告增量指标的区间估计，例如95%区间；不能把每只股票每天的样本视作全部相互独立。

启用条件：数据口径与覆盖通过核对；在独立时间测试中相对预先指定基线具有可解释的改善；概率校准可接受；最低样本量、主指标及容忍阈值在测试前冻结。只在某只股票、某一段行情有效的结果不能自动推广到所有股票。

同类样本的历史上涨比例与模型预测概率分别显示。小样本、缺失过多或明显超出训练覆盖时，显示证据不足，不能输出看似精确的概率。

离线实验可以保存明确标记为未校准的原始概率，用于评分和校准研究；面向用户的预测概率展示仍按上述门槛控制，不能将内部实验输出描述为已验证结果。

收益预测和可交易收益分别评估。收盘后信号不能假设按当天收盘价成交；策略评估须另行规定次日实际可成交价格、持有期、A股适用交易约束、费用与滑点。方向准确率不能代替收益表现。

## 9. 架构、复用与保存

以下为拟议边界，暂不新增代码类型、端口或占位模块：

- **特征计算用例：** 接收标准日线／同钟累计量、截止时点和配置，返回特征值、缺失原因及版本；独立于Qt、供应商和预测算法。
- **预测用例与引擎端口：** 与现有区间AnalysisService并列，复用标准行情、任务管理与来源信息；不把未来预测塞进旧阶段评分中。
- **离线评估任务：** 独立进程按股票／日期分批运行，支持取消、进度、检查点和资源上限，不在界面线程训练。
- **研究档案：** 保存不可变输入快照、数据修订、实验配置、特征／目标／阶段／模型／校准版本和已发出的预测。不得使用会覆盖旧帧的market.sqlite充当完整历史档案。
- **结果缓存：** 键包含证券、特征截止点、数据内容版本、目标跨度、特征参数、阶段／模型／校准版本；仅取得时间刷新但内容未变化时可复用。
- **预测与事后评价分离：** 已发出的记录不可改写；未来标签成熟后新增评价记录，保留预测时可知信息。

面向用户的结果至少包含证券、基准交易日、截止时点、H1／H2目标日期、状态、数据与模型版本、特征及口径、缺失原因、样本适用范围。经过验证后才展示预测概率；未启用时用户概率字段为空，内部实验记录单独保存。

建议状态包括：仅特征、待验证、数据不足、可用预测、数据过期、不适用、失败。状态与界面文案需一致，失败或缺失不得默认为中性或50%。

日线特征计算复用已有后台有界调度和缓存约束。普通本地交互沿用架构中的p95约300毫秒目标，仍须实测。批量训练／回测与15秒行情轮询分离，不每次报价更新都重新训练模型；预测任务过期后不得覆盖新股票或新截止点。

## 10. 界面与Ctrl选区

在研究面板中规划独立的“量价特征／未来1—2日”视图，保留现有区间分析操作。用户可以查看：

1. 当日完成状态、预测基准日期和目标日期。
2. 较昨量／较前2日均量／较5日和20日均量、多周期位置及收盘结构。
3. 固定窗口阶段评分、支持与竞争解释、数据缺失。
4. 尚未验证时的功能状态；通过验证后，各目标的概率与适用范围。
5. 同类历史样本数、正收益比例、收益分布及基线对照入口。

Ctrl任意选区仍用于探索该区间。若以历史选区末日为预测基准，只能使用该末日及之前数据，并自动读取固定回看窗口；选区长度不隐式改动预测模型输入。选区末日未来的标签必须在回放模式按可知时点隐藏。

日K未完成时仅展示明确标注的进行中特征，不套用收盘模型输出正式概率。基础数据不足、过期缓存或模型不适用时保留原因，不能继续展示上一只股票／上一个日期的概率。当前0.2界面不因此立即增加预测按钮或占位百分比。

## 13. 方法背景

- [Dynamic Volume-Return Relation of Individual Stocks](https://web.mit.edu/wangj/Public/Publication/Llorente-Michaely-Saar-Wang02.pdf)：研究交易背景、成交量与收益延续／反转的条件关系。
- [Trading Volume and Serial Correlation in Stock Returns](https://dash.harvard.edu/entities/publication/73120378-8365-6bd4-e053-0100007fdf3b)：研究成交量与日收益动态关系。

这些研究提供方法背景，不验证本文组合在A股未来1—2个交易日的准确率，也不提供本项目可直接使用的阈值或已校准模型。
