# 猫爪／猫头鹰数据：配置、周期与本地缓存

日期：2026-11-05。版本：0.10.0。预测专项仍为P2，当前交付行情、图表与透明逐笔统计。

## 接入及密钥

已从[猫爪Agent页面](https://meoz.cn/docs/agent)及[猫头鹰Agent页面](https://t.meoz.cn/docs/agent)下载、检查并安装官方`meoz`、`meoz-market` Skill 0.2.5，读取其说明并同步官方接口目录。接口契约为1.0.48、清单1.0.51。本机安装位于`~/.codex/skills/`，下一轮Agent会话可识别；程序使用独立适配器，不依赖Skill脚本安装。

API Key优先读取`MEOZ_API_KEY`，其次`~/.meoz/config.json`，再兼容`~/.meoz-market/config.json`。本机已通过官方脚本隐藏输入配置，文件权限为0600；不写入代码、请求档案、日志或Git。其他电脑执行：

```bash
python -m chengchuan.meoz configure-key
python -m chengchuan.meoz status
python -m chengchuan --provider meoz --symbol 002318 --interval min15
```

`--provider auto`在已配置时优先猫爪，否则保留腾讯日K／采样分时；`--provider tencent`可显式选择旧源。搜索代码／名称／拼音继续使用公开搜索，不消耗付费调用。

0.5.1也可在GUI周期上方切换数据源，点击“配置猫爪”通过隐藏输入保存本机密钥，GUI和上述CLI共用原子配置函数。密钥仍按环境变量优先；配置文件保留其他字段、临时文件权限0600后原子替换。取消或保存失败不切换源，不回显输入。换电脑需要在目标电脑配置，Git不携带密钥。

0.6将此入口统一到“设置 → 数据连接”，也可从侧栏或Ctrl＋逗号打开。输入框只用于新密钥，不回显已有密钥；留空保留、取消不保存，状态“已配置”仅表示本机配置存在，不代表套餐权限已联网验证。输入新密钥默认选择猫爪，可显式改选来源；若环境变量已设置，其优先级仍高于页面保存的文件。

普通偏好保存到工作区独立`preferences`记录，不含密钥；密钥先写私有文件，再保存其他偏好，跨存储部分成功会明确提示。更新检查间隔可在15—3600秒间设置，仍遵守180秒源缓存与本机额度保护。本地存储页显示打开时的路径和用量，打开页面及修改显示偏好不请求付费API。

数据源选择保存在工作区，未显式传`--provider`时恢复；首次仍自动判断。腾讯下只启用分时／日K，其余周期置灰并提示切换猫爪；猫爪显示12周期能力，缺少配置时提示，不把能看到接口等同于已经获得权限。源切换不消耗查询额度，随后实际加载行情才按缓存／权限／额度处理。

## 图表与真实口径

| 图表 | 代码 | 基础数据及处理 |
|---|---|---|
| 分时 | minute | 最近可得交易日真实1分钟数据的收盘价线，显示源累计VWAP |
| 五日 | five_day | 最近5个市场交易日分钟收盘价，分日断开并显示日期、VWAP和基准线 |
| 日K | day | 原始日线OHLCV及成交额；初次查询2000年起接口实际可得记录 |
| 周／月／季／年K | week/month/quarter/year | 按ISO周、自然月、自然季度、自然年聚合真实日线 |
| 1／5／15／30／60分钟K | min1/min5/min15/min30/min60 | 最近5交易日真实1分钟OHLC共享计算；午前／午后、隔日独立 |

日线及分钟的成交量按手转股，乘100；成交额为元。已核对久立2026-11-04全日241个分钟桶与日线：成交量均为8876300股，成交额均为150120000元。

分钟轴采用`trademin`收盘桶；09:30桶可能带09:25来源时间，包含开盘集合竞价。09:30竞价量进入首个较大分钟桶，不重复也不丢弃；60分钟桶截至10:30、11:30、14:00、15:00。未完成桶保留已取得的末条时间，不标为未来已完成时间。周/月/季/年当前周期结束前仍会变化。

缺少价量的行不补造，成交额缺失保持None；缺少交易日或分钟不补零。合成K线是已取得记录的开、高、低、收与量额汇总，不能代表缺失部分。最新日K的名义15:00标签不能证明已收盘。日线没有真实报价时间时不伪造Quote，分钟末价不称为逐笔实时价。

全部价格目前不复权。多周期区间计算基础统计；周/月/季/年及新分钟周期尚未套用日线阶段规则。五日与分钟K的默认5日覆盖是加载策略，不是套餐权限上限；0.5支持跳转指定日期，起止范围和长历史分页仍待加入。

0.7将全部12周期扩展至六个常用指数。指数使用独立身份，例如`index:sh000001`，不会与股票`sz000001`混用缓存。指数分钟接口没有VWAP，图中不生成指数均价线；上表VWAP仅适用于提供相应字段的个股来源。指数历史日线裸代码响应成交额存在单位差异，未核定的字段保留缺失，不能把个股成交额换算规则无条件用于历史指数日线。详见[指数与指标口径](INDEX_DASHBOARD.md)。

## 指数摘要与行情详情

顶部批量获取六指数摘要，点击切图并保留当前周期。右侧“行情”提供当日或历史对应日的基础价量、换手、估值及资金分类，不随周／月聚合扩大指标周期。

| 接口 | 用途 | 复用方式 |
|---|---|---|
| `indexdaily` | 六指数最新点位、昨收、高低、量额及历史日线 | 最新一次批量查询六只；单指数历史归档并增量维护 |
| `index_minute` | 指数分时、五日与分钟K | 六只按日批量，同一日只补取一个包；不同周期共享 |
| `valuation` | 个股量比、两种换手、PE／PB、总／流通市值 | 按证券和交易日缓存，与图表聚合周期分离 |
| `fundflow_kp` | 个股主力分类买卖与净额 | 同日共享，缺少权限不阻塞图表 |
| `screening` | 同日涨跌家数、主力净额按全市场／沪深／创业板／科创板分组 | 一份全市场快照复用各范围，显示无报价与资金覆盖家数 |
| `emoindic_daily` | 筛选统计不可用时的全市场汇总 | 保留其来源范围，不能降级生成沪深或板块分组 |

统计范围不是指数成分名单，界面明确标注；沪深300与中证500当前展示全市场背景。历史成分股统计需另接名单与调整日。个股换手率使用源字段；指数接口没有换手率，显示缺失。指数量比按当前每分钟量除以前5个已取得交易日每分钟均量计算，排除午休，标为“计算”。资金分类并不代表真实机构账户或持仓。

原始响应及请求账本继续共用`~/.meoz/chengchuan.sqlite`。摘要／详情另存到当前来源的工作区行情缓存，具有独立的格式、类型、证券与日期校验，最多保留201条展示记录，不挤占图表缓存上限。历史估值／资金／市场统计需确认对应日15:15后取得，旧盘中响应不冒充收盘。完整盘后快照复用，部分失败允许短期重试，底层180秒与额度保护仍生效。

本机体验账号本轮已成功读取上述接口；套餐权限仍由服务器实际响应决定，不把文档目录可见当成永久授权。指数真实图表、单位核对和请求记录见[0.7验证](VALIDATION_DASHBOARD.md)。

## 日期跳转与参考价格

图表下方日历选日后，分时加载该日（无交易则上一市场交易日），五日／分钟K加载截至所选日最近5个市场交易日；日周月季年使用日线档案截断至所选日再聚合，不带入后续记录。选周/月/季/年中的某天，当前桶仅包含截至该日的数据。数据缺失／无权限时明确提示，不自动跳成今天。

翻月不请求；近期日历优先复用，不足时使用[范围交易日历](https://meoz.cn/docs/query/calendar/range)，分钟仍调用已核对的历史1分钟接口。首次查看未缓存日期可能增加日历和分钟调用，五日／分钟K最多需要对应5日数据；相同日期和不同聚合周期共享原始分钟缓存。历史帧与最新帧按日期隔离，不覆盖最新画面或股票目录。F5保留日期且不绕过底层付费保护，返回最新才恢复自动更新。

日线`pre_close`按日期保存在帧内，分时和日K悬停优先用当日昨收；周月季年比较上一根K线收盘。旧本地快照缺昨收时可使用前根未复权收盘并明确标注，基准缺失显示“—”。浮窗时间来自记录本身，分钟数据秒通常为00，不代表提供秒级逐笔；光标价与记录价格分别显示。历史重建仍可能受供应商修订影响。

## 额度与缓存

[官方套餐页](https://meoz.cn/pricing)：体验版29元／周，猫爪与猫头鹰共享每日100000次，高频接口每接口100次／日，每秒3次。

本机`~/.meoz/chengchuan.sqlite`跨窗口／进程共用，保存原始成功响应、日线逐日档案、请求预留与失败冷却：

- 保守按每接口95次、总计90000次保护；所有接口均按95次保护，实际比仅限制高频接口更严格。live／history同名apiname合并计数，两站共用限流。
- 发HTTP前事务预留，失败、超时、中断均不退款；本地午夜按北京时间切换日计数。请求间隔至少0.4秒，禁止无界重试。
- 已存历史分钟直接复用；付费行情至少180秒复用，F5也不绕过。0.8最新自动补齐按午休11:33／盘后15:45等时点确认，考虑盘后量额；齐全后暂停查询。15秒定时器是本地调度，不等于每次发付费请求。
- 交易日历每日复用；冷启动日线完整取得后逐日落档，后续只从末条日期起增量更新，不反复下载完整历史。
- 重复查询租约抑制并发重复调用；错误短期冷却，401／403冷却更长。网络或额度问题优先保留可用旧数据，显示原因及原取得时间。
- 缓存命中、离线回放不增加HTTP计数。缓存512MB上限，超限明确报错，不自动删历史；原始响应单次16MB上限。

本机计数仅包括本应用的预留，不能推知其他设备、网页或Skill直接查询的账号用量。不能将“95减去本机计数”当作服务端真实剩余额度。界面显示本机用量及这一限制，服务端拒绝后不持续请求。

GUI窗口缓存与腾讯分库存储，序列化格式兼容旧版，并保留来源、均价与基准线。跨电脑携带缓存时单独迁移数据文件并配置自己的密钥，不把账号配置提交到Git。

0.8热力图使用`theme_daily(type=hy/gn)`与增加成交额的`screening`，个股热力图和指数统计共用筛选响应；按需加载，不跟随每15秒轮询。公开分类资金页单独使用并标注东方财富来源，不占猫爪额度。0.9板块下钻增加`theme_members`按类别缓存，复用加入最新价的同日筛选响应。体验保护保持，见[刷新与市场视图](MARKET_VIEWS_AND_REFRESH.md)。
