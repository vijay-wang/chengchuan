# 0.7指数摘要与行情指标

日期：2026-11-04。版本：0.7.0。

## 使用方式

窗口顶部显示上证指数、深证成指、创业板指、沪深300、科创50、中证500的点位、涨跌幅和数据日期。点击卡片后沿用当前图表周期，打开该指数最新图表；选中卡片高亮。名称、常用简称和带交易所代码也可搜索，自选支持保存指数。

指数与股票身份独立：上证指数为`index:sh000001`，平安银行为`sz000001`。直接输入裸`000001`仍打开股票，上证可输入`sh000001`或点击顶部卡片。图表、缓存、自选及异步任务均使用独立身份。

猫爪／猫头鹰来源支持这六个指数的分时、五日、日／周／月／季／年K，以及1／5／15／30／60分钟K。日线聚合与分钟聚合复用已取得原始数据；分钟K默认覆盖最近5个交易日。日期跳转与个股相同：查看指定日或截至该日的记录，切周期及F5保留日期，返回最新后恢复更新。顶部摘要始终是最新概览，不随历史日期倒退；点击摘要会离开历史浏览。

腾讯基础源支持指数日K和采样分时及当前行情字段，其余周期保持置灰提示；不会把采样分时拼成真实分钟OHLC。未取得历史指标时显示缺失说明。

右侧默认打开“行情”；Ctrl拖选完成后自动打开“区间分析”。股票原有研究流程保留，指数只使用基础统计，不套用个股吸筹／洗盘等阶段规则，不生成个股量价预测。后续预测增强仍为P2。

## 个股字段

| 字段 | 来源及口径 |
|---|---|
| 最新价、昨收、今开、最高、最低 | 当日原始日线价格；历史浏览使用所选日对应数据 |
| 涨跌额、涨跌幅 | 最新价减昨收；涨跌额除以昨收乘100 |
| 振幅 | （最高－最低）／昨收×100，昨收或高低价无效则缺失 |
| 成交量、成交额 | 源成交量由手转股，乘100；成交额为元，界面按万／亿缩写 |
| 量比 | 猫爪`valuation.volume_ratio`原值，不与其他来源拼算 |
| 换手率、自由流通换手 | `turnover_rate`和`turnover_rate_f`分别展示，均为百分数，不混用分母 |
| 市盈率TTM、市净率 | `pe_ttm`、`pb`；负PE可能表示亏损，不当作缺失或低估判断 |
| 总市值、流通市值 | `total_mv`、`circ_mv`，元 |
| 主力净额、主力买入、主力卖出 | `fundflow_kp`分类金额；买卖方向按字段定义，卖出量展示绝对额，净额保留正负 |

指标按**交易日**加载，与图表周期分开。查看周K、月K不会把整周／整月的成交量、振幅当作当日指标。各字段悬停可查看来源、取得时间及计算说明。报价时间、图表记录时间、指标取得时间分别展示，取得时间不冒充成交时间。

资金字段是供应商对成交的分类统计，不能据此识别真实账户、机构持仓或隐蔽拆单。界面只呈现源定义下的金额。

## 指数字段与统计范围

指数价格单位为“点”；昨收、今开、高低、涨跌、振幅、成交量和成交额来自指数日线，不拿成交额除以成交量生成所谓指数VWAP。

猫爪指数量比标为“量比（计算）”：当前每分钟量／前5个**已取得交易日**每分钟均量。完整交易日按240分钟；盘中按源有效时点计算已经过的交易分钟，排除午休，14:35为215分钟。前序不足5日、量为零或缺少有效时点时不计算。这是本软件的明确口径，未承诺与所有终端完全一致。

当前指数接口没有换手率，显示“—”及原因，不用个股股本代替。历史指数日线的裸代码响应与带交易所代码的最新响应存在成交额单位差异；尚未核定的历史日线成交额显示“—”，原始缓存不改写、不猜乘数。已核对的最新快照及分钟成交额按元保留。

涨跌家数与资金来自同日全市场筛选快照，按范围汇总。范围标题、日期、无报价家数、资金覆盖家数同时展示：

| 当前图表 | 显示的范围 | 边界 |
|---|---|---|
| 上证指数 | 沪市A股 | 不是上证指数成分股全集的精确计算 |
| 深证成指 | 深市A股 | 不是深证成指500只成分股 |
| 创业板指 | 创业板A股 | 不是创业板指成分股 |
| 科创50 | 科创板A股 | 不是科创50成分股 |
| 沪深300、中证500 | 全市场A股（源范围） | 未接入各自历史成分名单，不伪装为指数资金 |

上涨／下跌／平盘按`pct_chg`正、负、零统计；缺失计入“无报价”，不算平盘。主力净额只汇总非空的`main_net_amount`，同时显示覆盖数，例如“2316/2318家”。未覆盖部分不会补零。筛选接口不可用时，可以降级为`emoindic_daily`提供的全市场汇总，保留其范围标签，不能据此恢复沪深或板块分组。

这些统计并非精确的指数成分股涨跌／资金统计。后续如接入成分名单、调整生效日和成分级资金，需另行计算、命名和验证。

## 性能、缓存与错误恢复

六指数摘要共享一次批量日线查询；同一天六指数分钟共享一次批量查询，五个交易日最多五批，而非每个指数重复请求。指数历史日线首次分开建档，随后复用并增量更新。每个响应有行数边界，达到6000行的全市场或批量分钟响应不能当成完整数据悄悄截取。

图表、摘要、详情使用独立后台任务和带身份的结果检查。快速切股、切源、跳日期或导入快照后，上一任务的迟到结果不能覆盖新上下文；关闭窗口取消任务。详情或统计失败不阻塞可用图表。

原始请求继续经过本机共享额度保护，至少180秒付费源缓存；F5不绕过。摘要／详情另有持久化展示缓存，区分来源、证券和日期，盘后完整数据复用，部分失败短期重试。失败时保留旧数据及原时间，不贴上新的取得时间。历史查询需确认缓存至少在对应日15:15后取得，盘中快照不会冒充历史收盘值。

缺失、无权限、来源不支持、时间或单位不能确认的字段显示“—”；真实零值正常显示。设置页提供本机最新请求计数，行情说明中的计数是该次取得时的快照，均不包含其他设备或客户端的请求。
