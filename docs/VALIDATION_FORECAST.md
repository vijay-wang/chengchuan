# 0.3量价预测研究：实施与验证记录

日期：2026-11-04。版本：0.3.0。结论：收盘特征、过去样本训练、H1／H2方向、逐日预测与真实结果对照、GUI／CLI和导出均已跑通。**当前仅为原始价格工程诊断，尚不能认定具有稳定投资预测优势。**

## 已交付及使用方式

桌面右侧“量价预测”页可指定D，或勾选跟随Ctrl选区末日，计算方向、逐日验证、取消和导出。预测使用固定历史窗口，不使用选区长度决定输入。回测严格要求目标日早于所选上界；H2是两交易日累计方向。表格显示C组最近40条，导出保留所有A/B/C记录、缺失及不预测原因。

CLI `python -m chengchuan.forecast predict|backtest`不需要Qt、模型API密钥或新增ML依赖。支持旧标准日线快照、带观察时间的新输入档案、离线复算、指定基准／开始／严格上界、排除异常日期及自定义研究档案。具体命令见[README](../README.md#使用量价预测)。

当前日K确认：本地时钟及来源观察时间至少15:15，报价至少15:00且同日，时间不能在未来；名义15:00的K线时间戳本身无效。过去日线属于历史重建，不能证明取得了当时未修订的版本。GUI导入模式不携带最新报价元数据，保守使用过去日期；CLI新输入档案可还原观察／报价时间。

## 模型与隔离

- 特征：较昨／前2／5／20日均量，此前20／60日高低区间位置，1／5／20日变化、缺口、影线、收盘结构、波动与量价交互，固定5／20日的四类阶段分数。
- 模型：标准化近邻分类，默认k21，最少40、最近160个成熟样本；参数在本次回放结果前固定，未据此寻优。填补中位数、距离尺度仅拟合当时训练样本；并列类别不预测。
- 三组：A价格、B增加量价、C增加阶段分数。没有把阶段规则直接当作涨跌概率。
- 隔离：逐D截断行情／分类／基准并重算摘要，只训练标签日期≤D的样本；预测函数拒绝未来行。先事务保存所有预测，再独立评价未来结果。
- 档案：快照、实验、预测、评价分别保存；同一标识不允许内容覆盖，重复运行不增加条数。逻辑D、实际执行时间和数据版本分开。
- 日历：核对2025／2026沪深休市安排。缺失目标不顺延，缺失基准交易日仍留记录；零量及不足60个历史交易日不形成合格输入。未知年份拒绝猜测。

日历依据：[上交所2025休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20241223_10767108.shtml)、[2026休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)。
