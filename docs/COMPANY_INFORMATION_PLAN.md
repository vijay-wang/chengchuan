# 公司资料功能规划与数据口径

2026-11-05。基于澄川0.13、猫爪Skill及官方目录1.0.52。按以下范围交付0.14，八类资料已完成基础实现，交付范围及实测以[操作说明](COMPANY_INFORMATION.md)和[验证记录](VALIDATION_COMPANY_INFORMATION.md)为准。沿用Python／Qt、分层与本地缓存，预测增强仍为P2。

## 功能与入口

增加独立“公司资料”工作区，左侧入口及行情页入口打开当前股票；与市场研究页分开管理任务，但共用虚拟表、证据元信息、原始缓存和追加档案。选择股票、截至披露日、查询年限、报告期和修订模式后手动查询；不在切股或鼠标移动时下载所有资料。

| 分类 | 本期实现 | 数据 |
|---|---|---|
| 公司概览 | 名称、地区、行业、上市信息、实控人原字段；最近可用交易日的估值、市值、股本与资料状态卡 | `stockbasic`、`valuation` |
| 财务指标 | 原指标历史表、按报告期曲线、字段说明；单位未确认的指标明确标为原值 | `finance_indicator` |
| 财务三表 | 利润／资产负债／现金流量表；按科目横向对比报告期，可切回原始行，保留报表／币种代码 | 三张`finance_*`报表 |
| 股东股本 | 十大股东、十大流通股东、股东户数、股本事件；同类表相邻报告期的精确名称对比 | 两类top10、`finance_holder_number`、`finance_capital` |
| 分红送转 | 方案进度、每股分红／送转、登记日／除权日／派息日；与预案和实际阶段区分 | `finance_dividend` |
| 业绩披露 | 财报预约与变更、实际披露、预告区间、快报，分别列表 | `finance_disclosure_date`、`finance_forecast`、`finance_express` |
| 公司公告 | 日期、标题、类型、摘要和原文链接；本地过滤，用户点击才打开原文 | `finance_announcement` |
| 问董秘 | 问题、回答、双方时间、编号与修订；本地搜索，源覆盖与回答日期单独说明 | `interactive_qa` |

支持返回个股行情及题材证据、Markdown／JSON导出。原文仅明文呈现；外部链接只允许有效HTTP(S)，不会自动打开浏览器、下载附件或加载网页脚本。所有开发验证强制后台offscreen。

## 必须保留的事实与限制

1. **服务选择**：基础信息和估值用官方日内操作，其余选`history90_reference_*`历史契约，普通历史节点；不根据日期猜服务，也不回退日内接口。
2. **字段与单位**：新版财务指标、三表、股东股本改为VIP原字段，完整保留大小写、新字段、零及null。尤其`finance_indicator.net_profit`是净利率，不能冒充利润金额。文档对多数金额／比率注明尺度尚未确认，本期显示“原值”，不擅自写元、万元、百分数或计算资产负债率、单季利润、年化／TTM。分红、业绩快报、估值等明确单位的字段按契约展示。
3. **时间**：财务类传`as_of`和`version=latest/all`，显示报告期、披露日期、版本及并列版本标志。按自然日回看，不宣称完整分钟级“当时已知”样本；公告的披露时间可能回落到日零点。问答按回答时间筛选，不显示截至日之后的答复。基础资料是当前档案，单独标明，不回填为历史实控人状态。
4. **修订与口径**：并列／不明确版本不强行选一条。报表类型和币种有源代码时分组，未确认枚举不擅自叫合并／母公司或人民币。曲线展示报告期原值，可能为累计数据，不当成独立单季。
5. **股东对比**：十大股东和十大流通股东独立比较，按完整期、未歧义版本及精确名称匹配；前十名单新增／消失不等于从零买入／清仓。数量和比例单位未确认时仅算同源原值差；不能据名单推断实时北向、真实账户或实际净买额。重复名称或修订无法唯一对应时不生成确定差值。
6. **覆盖**：多数历史契约首期写2026年至今；公告保留2025—2026部分记录，问答自2026-06-26累积。按实际返回和分页完整性说明；无记录、无权限、未覆盖及错误分开，空值不补零。

## 性能与工程

按分类懒加载；查询参数稳定，资料缓存按接口节奏设置时效，同日重复查看优先读本地。沿用可终止进程及迟到拦截，切条件／源／关闭会取消；保留旧内容并提示所属条件。单次只查一股，分页、行数和图线数量有上限。最新视图和导出保留来源、获取、首次观察、版本及完整性，密钥不进入Git或研究卡。

分层：domain放公司请求／事实卡／快照；application编排分类、股东对比、矩阵和曲线；infrastructure适配契约、分页及追加档案；UI呈现和导航。共用证据导出，不复制HTTP认证。必要的字段说明扩展须兼容0.13档案。

## 验收

- 真实久立样本核对全部资料接口，至少再用另一只股票验证代码隔离；费用／权限错误不遮掉其他分类。
- 覆盖未来披露排除、财报预告未来报告期保留、修订歧义、同名股东、前十缺失、股东比例尺度未确认、累计报表不拆季、负利润／负现金流、零／null、新字段及分页边界。
- GUI验证切股／切分类取消、旧结果不串股、缓存复用、表格排序筛选、矩阵切换、字段工具提示、原文链接协议、导出和关闭；全部offscreen，不访问用户前台。
- 完整回归、Ruff、wheel无Qt核心复验、凭据扫描、Git提交及本地合并；不推送远程，不把未验收的平台和接口覆盖描述为通过。
