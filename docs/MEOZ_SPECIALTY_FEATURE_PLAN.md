# 猫爪特色数据功能规划

日期：2026-11-05。规划基线为澄川0.12.0、猫爪Skill 0.2.5及接口目录1.0.51；现已在0.13实现F1—F6基础工作流及共享快照能力，操作和剩余范围以[实现说明](MEOZ_RESEARCH_WORKSPACE.md)为准。龙虎榜已依据官方历史契约和迁移提示接通历史服务并完成真实验证。已有功能正确性、稳定性为P0；研究功能为P1，盘后／14:35下一日预测仍为P2。

推荐先交付F1“精选板块轮动”和F2“题材证据卡”：它们能连接已有热力图、股票列表、行情图与逐笔研究，回答“哪个方向活跃、哪些公司相关、依据是什么、价格和资金是否呼应”。

## F1：精选板块轮动与资金变化

**使用流程**：市场热力图选择“精选一级／二级” → 点击板块 → 查看当日累计涨幅、供应商强度、成交额与资金曲线 → 拖选一段完整时间 → 查看成份股 → 打开个股现有图表及逐笔。二级板块通过`p_symbol`返回所属一级，保留源内层级。

第一期包含：

- 排行表按强度、涨跌幅、主力净额或300万元大单净额排序；“强度”按供应商字段命名，不显示为上涨概率。
- 一级板块的完整5分钟桶曲线，及当日累计资金曲线；标明源时间、最新完整桶和覆盖。
- 展示同日连续、覆盖完整的5／15分钟净额变化。累计值可差分为区间变化，字段为负的卖出额保留其符号，不重复取负。涨幅差若按百分点展示，不冒充区间收益率。
- 提供“价格上升／回落×净额增加／减少”的事实筛选；阈值可配置，展示满足的条件，不直接命名为主力吸筹、出货或买入建议。
- 与现有个股列表联动，支持加入观察、固定板块、导出本地研究卡。

**数据与限制**：

| 接口 | 已核对用途与覆盖 |
|---|---|
| [精选一级行情](https://meoz.cn/docs/query/theme/themedaily_jx)、[二级行情](https://meoz.cn/docs/query/theme/themedaily_jx-child) `themedaily_jx` | 强度、涨幅、涨速、成交额、主力净额、300万元大单净额等；一级文档历史自2026-03-20，二级按实际覆盖 |
| [5分统计](https://meoz.cn/docs/query/theme/minute-stat) `thememinute_jx` | 一级板块，每5分钟只发布完整桶；从09:25起的当日累计统计，不是独立5分钟成交额；首期历史仅最近3个交易日，实际返回为准 |
| [当日资金](https://meoz.cn/docs/query/theme/themefundflow-jx) `themefundflow_jx` | 一级／二级，最新交易日分钟累计资金，09:29—11:31、12:59—15:01每分钟更新；不能查询任意历史日 |
| [精选股票池](https://meoz.cn/docs/query/theme/jx-members) `thememembers_jx` | 当前股票池，支持一级／二级；当前名单不当作历史名单 |

现有行业／概念板块与精选板块代码不是同一命名空间；保留来源、层级、原始代码，不按相同名称或去掉后缀强行合并。父子板块、不同题材可能重叠，不将其资金简单相加作为全市场资金。

这些统计接口没有承诺完整价格OHLC，先画“涨幅／强度／资金研究曲线”，不把统计点伪造成真实K线。供应商所谓主力分类与本软件原始委托名义金额分开，不做数值强行对账。

**验收**：10:00历史视图不出现10:05桶；当日累计与区间差分分开；午休和缺口不补造连续数据；父子代码不串；分页到边界不能当作完整；缺少历史资金时明确提示而非回退今天资金。

## F2：题材证据卡与龙头跟踪

**使用流程**：打开个股 → 右侧“题材证据”卡 → 查看相关题材及来源 → 展开题材树／成份表 → 查看业务关联说明、供应商标签和收盘排名 → 与K线事件、自己的研究备注联动。

第一期采用题材树、表格和证据卡，不先开发大型可视化关系网。提供按股票反查题材，以及按题材查看股票两条路径；可将观察依据导出为Markdown／JSON，交给其他AI继续分析。

| 接口 | 使用方式与限制 |
|---|---|
| [题材库](https://meoz.cn/docs/query/theme/lib-kp)、[详情](https://meoz.cn/docs/query/theme/lib-detail-kp) `theme_lib_kp`／`theme_lib_detail_kp` | 当前题材及嵌套简介、说明和股票列表，每日00:30同步；仅最新快照。详情不支持`fields`，要新增嵌套结构适配 |
| [板块原因](https://meoz.cn/docs/query/theme/reason) `theme_reason` | 区分`xgb`选股宝及`jygs`韭菜公社原文；按源内代码关联，不能将相同名称自动认定为同板块 |
| [最正宗](https://meoz.cn/docs/query/theme/jx-authentic) `thememembers_jx(tag=authentic)` | 最近已完成交易日的当前标签，仅最新截面；展示为供应商标签，不解释为真实业务收入占比 |
| [龙排名](https://meoz.cn/docs/query/theme/jx-long) `thememembers_jx(tag=long)` | 收盘后日度快照，通常约15:40完成，文档历史自2026-03-20且分批回补；不是实时龙头排行 |

卡片至少区分“供应商标签”“三方解读”“公司披露”“用户判断”。当前库如有AI硬件、核聚变或固态电池相关说明，只证明源将公司纳入题材；订单、收入或客户关系需要相应公司披露证据。AI摘要若后续加入，应引用可点开的证据，不自行补写订单金额和确定性因果。

“龙排名”保留完整板块原始排名层级及并列组。服务端先按股票过滤后的数组位置不代表绝对排名，因此不能把过滤后第一只显示为龙一。仅最新标签／详情查看历史日期时单独注明当前快照，不能回填为当日已知信息。

**验收**：无快照与无权限分开；部分板块无标签仍可使用普通成份；同名题材不误并；并列排名及过滤排名正确；当前标签不混进历史回放；题材HTML只做受控展示，原文与摘要能追溯。

## F3：市场情绪与封单时间线

**市场页**在现有指数／涨跌家数基础上增加市场宽度、极端涨跌分布、首板／二板／高板数量、最高连板、炸板率、昨日涨停股今日表现。用实际指标组合说明“修复／分歧／走弱候选”，不直接输出大盘已企稳或未来上涨概率。

**个股页**增加历史封板／开板事件轨道、封单额曲线、开板次数和回封间隔；从事件点击回到原图相应位置。只展示已核对事件类别，未知编号保留原值。

数据：[情绪周期](https://meoz.cn/docs/query/market/emoindic-daily) `emoindic_daily`、[涨跌停池](https://meoz.cn/docs/query/stock/limit-pool) `limit_pool`、[昨日涨停](https://meoz.cn/docs/query/stock/limit-pool-yes) `limit_pool_yes`、[异动历史](https://meoz.cn/docs/query/stock/limit_event_v2_history) `limit_event_v2_history`、[分笔封单](https://meoz.cn/docs/query/stock/tick-fd) `tick_fd`。现有情绪基础接口可复用，扩展字段和事件仍需联调。

关键口径：

- 昨日涨停池的标准字段属于查询日，昨日字段为`pre_*`等；不能将日期再向前偏移一次。
- 分笔封单只覆盖涨停侧，不补造跌停侧同等覆盖。封单减少是成交、撤单和新增的合成变化，不全部当作撤单。
- 源`fd_decrease_rate_12s`的分母为当前封单额，不能改叫通用撤单率。仅在有完整原始事件关联时，另列实际已确认撤单。
- 连续封板60秒的事件最早09:31发生，不提前标到09:30。历史事件是原始Tick重放产生，不自动等于当时已发布的通知。
- 首期先做历史／手动刷新闭环；实时异动订阅单独联调。它与现有猫头鹰五档WSS不是同一接口，不能据旧连接结果推断其可用性。

**验收**：零分母、停牌、ST过滤范围、10%／20%等源内涨跌停口径可说明；事件时序正确且6000条上限不能悄悄截断；封单与实际撤单分开；跨日编号不拼接。

## F4：集合竞价透视

**使用流程**：盘前候选 → 撮合价／量与未匹配方向曲线 → 与昨日竞价比较 → 查看板块竞价背景 → 开盘后观察兑现，并进入原有分时图。

数据：[竞价指标](https://meoz.cn/docs/query/stock/daily_auc) `daily_auc`、[竞价分笔](https://meoz.cn/docs/query/stock/daily_auc_detail) `daily_auc_detail`、[竞价抢筹](https://meoz.cn/docs/query/stock/last-tick) `tick_history`、[板块竞价](https://meoz.cn/docs/query/theme/theme_auc_kp) `theme_auc_kp`。

显示撮合价、匹配量、竞价金额、未匹配方向与数量、竞昨量比、竞昨成交比、开盘抢筹幅度；板块列表保留今日新增／昨日延续／其他分组。可建立透明筛选条件，如竞价成交额、竞昨量比、开盘幅度、板块背景，结果称候选而非必涨名单。

`open_bid_pct`是09:25开盘价相对09:24最后有效竞价价的变化；`tick_history`为09:25前最后一笔基础行情，不能单凭接口名字断言机构抢筹。竞价前后`m_price`／`auc_vol`含义切换，必须带阶段。量按手转股，金额元；`um_side=null`表示无法可靠确定方向，不能当卖方。

板块竞价文档更新时间为09:28，因此不能在09:20或09:25的回放中提前展示该结果。其他更新起点受套餐与实际响应影响；官网标准版写09:25:45开始，专业版写09:15开始，不能把界面刷新频率当成源数据频率。

**验收**：价格时点切换、单位、空方向及昨日基准正确；只有09:28可用的信息不进入更早视图；分笔缺少历史时说明覆盖；自选变化不触发全市场无界下载。

## F5：龙虎榜席位档案

**使用流程**：股票历史事件轨道 → 查看上榜原因、披露区间及买卖席位 → 点击席位查看其已披露记录 → 与同期价格及成交特征比较。

数据：[上榜个股](https://meoz.cn/docs/query/history/longhubang/stock) `longhubang_stock`、[买卖席位](https://meoz.cn/docs/query/history/longhubang/seat) `longhubang_seat`、[游资名单](https://meoz.cn/docs/query/history/longhubang/hot-money) `longhubang_hot_money`。前两者文档历史2020年至今，盘后更新；名单为当前关联快照。

显示已披露买额、卖额、净额、占比、原因及来源，支持同席位多日记录与不同席位重合观察。买入榜`side=0`、卖出榜`side=1`；同名席位、同时进入两个榜及同股多原因均按原披露保留。默认不累加不同原因、1日／多日披露，也不把买卖榜重复项加成全市场净额。

证券汇总优先显示原汇总接口对应披露范围；没有可验证的归并依据时不输出累计净仓。“游资名称”只是公开关联标签，营业部不等同单一真实账户；席位净买入也不等同持仓增加。

**验收**：买卖方向不反、金额为元、重复原因和多日重叠不双算、披露滞后正确；没有发布时间的记录只放日期／盘后事件轨道，不暗示盘中已知。

## F6：热度与监管观察

两组信息并排展示，分别保留来源：关注榜新进入／持续在榜／多平台共现，及交易监管事实／严重异动计算候选。用户可选自选股、题材内股票，形成软件内观察列表。

数据：[热搜](https://meoz.cn/docs/query/stock/hotstock) `hotstock`、[最强风口](https://meoz.cn/docs/query/stock/fengk-kp) `fengk_kp`、[严重异动预测](https://meoz.cn/docs/query/stock/anomaly-forecast) `anomaly_forecast`、[交易监管](https://meoz.cn/docs/query/stock/point-monitor) `point_monitor`。

热搜最新模式主要字段`s,n,pc`，日度历史才有`rank,tradedate,type`；不把两种结构混用，不从未承诺排名的实时列表位置计算官方名次变化。最强风口每日最多30只，是源榜单而非全市场完整样本。

监管记录与异动候选分开：后者是供应商按规则、复权行情计算的候选，未来触发涨幅假设基准指数涨跌为0，**不是交易所正式认定**。规则说明、归属交易日、源时间与假设需可查看；不提供确定的未来监管价或把未触发状态当无风险。

**验收**：榜单模式、平台与日期隔离；正式记录和计算候选视觉有区别；候选回算能追溯规则和基准假设；没有数据不判定无监管事项。默认提醒仅软件内列表／角标，不抢焦点、不弹系统窗口，测试后台离屏运行。

## 两类后续专题

### 公司事件与公开持股结构

可在后续P1增加财报预约／变更／实际披露、业绩预告、公告、股东户数和十大股东变化时轴，服务久立等公司的持续研究。[财报预约](https://meoz.cn/docs/query/finance/disclosure-date)和[股东户数](https://meoz.cn/docs/query/finance/holder-number)文档首期覆盖2026年至今，必须同时展示统计日期与披露日期。

[北向持股明细](https://meoz.cn/docs/query/fund-flow/northbound-holding)自2024-08-19起为季度末快照；不规划实时北向持仓、实时大股东买卖或依据日K反推出账户身份。回购／注销等可先由对应公告证据支持，不假设目录中已经有专用结构化接口。

### 旗舰版资金与盘口派生研究

[DDX资金流](https://meoz.cn/docs/query/history/level2/money-flow-history) `level2_money_flow_history`、[十档盘口指标](https://meoz.cn/docs/query/history/level2/quote-aux-history) `level2_quote_aux_history`均明确仅有效旗舰版，体验及专业版不开放。因此它们不作为首批依赖，不依据990元专业版介绍推断可用。

这里指新增的派生统计接口，区别于软件现已接入的原始十档和逐笔；现有盘口功能不受此排期影响。

DDX按全天实际成交规模给原单分档后回填成交分钟，使用后续分钟信息；盘口辅助的`source_max_time>time`也可能使用晚于快照的源事件。可作为事后研究专题，但不能直接用于盘中／14:35的严格回测；即使盘后预测也要证明当时已发布，且源事件未超出决策截止。当前自己实现的原始委托分档与它不是同一口径。预测关联研究仍为P2，不因接口新增提前排期。

## 共享基础与代码边界

0.13已经接入以下共用能力；下文保留规划中的完整目标，具体交付范围见实现说明：

1. **身份**：独立题材身份`来源＋层级＋原始代码`，支持`801165k`等；题材库ID、精选代码、行业代码和三方解读代码分开。股票仍用现有规范身份。不得把题材代码交给股票接口；精选统计曲线使用有单位的有符号时序模型，不将负涨幅塞入股票价格模型。
2. **时间与覆盖**：保留业务日、桶开始／结束、源更新时间、源发布时间、首次观测时间、取得时间、版本和完整性。原始缓存虽保留完整响应，现有`ApiResult`主要透传行／分页；接入前需向用例透传`updated_at`、`total/offset/limit`及嵌套结构的元信息，不能把取得时间当源更新时间。
3. **本地档案**：最新截面和仅当日序列在首次取得后追加归档，不覆盖旧研究版本。已有历史回填只能称历史重建，不能证明当时可得；首期3日统计和仅当日资金需要从采集日起累积自己的观察样本。
4. **能力与错误**：区分可用、无快照／1002、无权限／403、部分覆盖和错误；目录存在不表示当前账号全部可用。一个板块缺标签不禁用整个功能，任何源失败不阻塞现有行情图。
5. **分层与调度**：domain放题材、统计点及证据契约，application做筛选／差分／时点过滤，infrastructure适配不同响应，UI呈现。复用现有任务取消、迟到拦截、虚拟表和本地存储；按源更新节奏刷新，5分钟源不因鼠标移动重查。后台任务、分页、内存和快照档案都有边界。
6. **界面**：左侧增加“市场研究”入口，页内切板块／情绪／席位，右侧仅增可折叠证据卡，不向现有侧栏堆六个新标签。默认保持原图缩放与选区；事件轨道与现有九档资金颜色分开，图层可单独勾选。所有验收默认offscreen，不打开用户工作桌面窗口。

## 分批验收与效果评估

建议顺序为共享基础 → F1精选行情／5分钟曲线／成份 → F2题材详情与证据（标签和收盘排名可选）→ F3情绪与历史封单 → F4竞价 → F5席位 → F6热度监管。

每批交付一个能实际操作的闭环，更新口径、缺失状态、运行检查和截图。先验证“数据正确、来源可追溯、时间不穿越、切股取消正确、图表不闪”；不为文档或单纯样式编写镜像测试。是否提高收益是另一个问题：先记录固定规则候选，区分来源日／首次可见时点，未来按时间留出、固定对照和交易成本评估；未校准前不输出概率，不把榜单标签当交易意图。
