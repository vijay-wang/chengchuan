# 澄川：功能路线与验收清单

以可用工作流推进；顺序可随用户反馈调整，不承诺未验证的交付日期。

## M0：工程与交互基础（本轮）

- [x] 产品名、模块边界、数据契约、旧代码迁移决定。
- [x] 本地Git基线，桌面包入口和可选依赖。
- [x] 现代深色研究工作台、真实日K／分钟采样分时、成交量、悬停信息。
- [x] Ctrl拖选、边界调整、Esc清空、后台计算与证据面板。
- [x] 有界任务、迟到结果拦截、分析缓存、SQLite工作区。
- [x] 图表纵轴随可见区域调整，避免历史高低点压扁当前走势。
- [x] 原引擎回归、依赖边界、任务错误恢复、真实鼠标交互测试。
- [ ] Windows原生环境、真实显示器高DPI和快捷键验收。
- [ ] 1万条行情帧时、内存及长时间操作基准。

## M1：行情工作台

目标：输入股票代码即可完成获取、看图和研究。

- [ ] 股票目录与代码／名称搜索，自选增删、排序及持久化。
- [ ] 独立数据获取用例，刷新、缓存、历史快照和来源切换。
- [ ] 数据能力、更新时间、实际覆盖、过期与网络失败状态。
- [ ] 日K／周K及分时切换，统一交易日时间轴。
- [ ] 补齐真实分钟OHLC后再开放分钟K线；不足时显示分时或明确无法提供。
- [ ] 更多图表快捷键与布局恢复。
- [ ] 缓存数据分析与CLI复算一致；切换股票不会显示上一只的结果。

## M2：图表和区间研究

- [ ] MA、EMA等基础指标，参数面板与独立指标注册。
- [ ] 选区收藏、命名、注释、标签和导出。
- [ ] A/B区间对比：同股不同阶段、不同股票同期、基准相对特征。
- [ ] 指标缺少字段时说明原因，避免整份分析因一个指标失败而丢失。
- [ ] 公司行为数据、复权显示和原始成交口径分离。
- [ ] 数据快照、模型、参数版本随研究记录保存。

## M3：回放与验证

- [ ] 历史回放控制器，图表和分析只使用当时信息。
- [ ] 按股票和时间留出样本、滚动评估、重叠样本处理。
- [ ] 模型对照、参数实验、结果分布；识别任务与收益预测分开。
- [ ] 特征筛选与批量任务的独立调度和资源预算。
- [ ] 研究项目和可复算报告包。

## M4：Level-2与执行行为

依赖：拿到可程序使用的数据样本、字段文档和明确授权。

- [ ] 逐笔委托／成交／撤单适配，序列和缺包诊断。
- [ ] 委托生命周期还原，快照与逐笔一致性核对。
- [ ] 被动承接、补单、撤单和执行簇研究。
- [ ] 模拟执行样本与真实带标签样本分开验证。
- [ ] 有误差验证后再提供候选执行金额区间；没有身份数据时不输出特定机构持仓。

## M5：专业使用体验

- [ ] 多图联动、可保存工作区、多屏与高DPI、主题及色觉设置。
- [ ] 绘图注释、事件时间轴、快捷键自定义。
- [ ] 数据修复工具、数据库迁移备份与恢复界面。
- [ ] 安装包、升级和回滚流程，Windows/Linux分别验收。
- [ ] 完成长期运行和规模测试后定义1.0发布范围。

## 每轮完成标准

能实际操作；异常路径可恢复；关键规则有验证；任务与缓存有边界；数据口径可解释；Git工作区整理并提交；文档描述与实际功能一致。
