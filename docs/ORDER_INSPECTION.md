0.12已改为按图中各交易日自动加载及缓存复用，五日均可显示各自的卡片和色条；缩放约束在实际数据内，详见[多日与缩放说明](MULTIDAY_ORDERS_AND_ZOOM.md)。

## 使用入口

1. 打开个股及日期，点击“盘口逐笔 → 读取逐笔”，或导入对应JSON。完整委托／成交分页到齐后可用；指数不套用个股逐笔。
2. “逐笔还原”默认直接显示“成交还原”：时间、价格、成交、卖单、买单；相邻同号格子合并。可切手／股、最新／最早在前。“原单列表”保留原价及成交均价，双击只在本页定位成交，不弹详细窗口。
3. “资金 → 原始委托分档”或展开工作台的分档页，用“统计未成交”“统计已撤销”选择口径。三处统计视图及图表同步；还原列表的显示筛选与统计筛选独立。
4. 图表下方勾选“悬停显示分钟委托分档”，移动到分时、五日或1分钟K，显示该条时间所在分钟的买卖九档金额与笔数。
5. 勾选“量柱标记”，再选择需要的金额档位。默认选中20—50万、50—100万；该分钟买卖任意方向出现对应档位原单，就在成交量图顶部固定色带位置画同色方块。多个档位在该分钟的横向宽度内并列，不互相覆盖，不同笔数不重复堆同色；放大图表可看密集区域。

勾选后后台逐日读取图中原单统计，在线源缺缓存时正常补取；离线源只读缓存。“补齐图中逐笔”可重试未完成日期。同股切周期复用已加载的各日摘要，切股和来源不混用；某日未发布或不完整不影响其他日期。鼠标移动、筛选和缩放不逐次请求API。开关在当前会话中保留，尚不保存到跨启动设置。

## 未成交与撤销的定义

| 条件 | 行为 |
|---|---|
| 未成交 | 截至分析时点，累计成交股数为0 |
| 部分成交、仍挂单 | 不属于“未成交”，取消未成交勾选后仍保留 |
| 部分成交后撤销剩余 | 属于“已撤销”，由撤销开关控制整张原单 |
| 勾选统计已撤销 | 仍按整张原始价格×原始数量计一笔，不按撤掉数量或已成交量改档 |
| 两开关都关闭 | 只统计至少发生一次成交、且截至分析时点未撤销的原单；部分成交仍用整张原单金额 |
| 零／重复委托号、超量关联、无可定价原价 | 始终不进入资金分档；不能通过勾选撤单将它们纳入 |

还原列表默认显示未成交及撤单；资金统计默认包含未成交、排除撤单，保留0.9统计默认口径。金额是委托名义金额，**不是实际成交流入／流出**。全体歧义／无价计数可能与撤单重叠，不能直接相加；旧分析分解计数继续保留，便于兼容既有核对。

## 成交价格与左右合并格子

“原单列表”的原始价格是申报价格，成交均价为真实成交额÷成交股数，显示四位小数；没有成交显示“—”。“成交还原”直接显示时间、实际成交价格和数量，后两列按参考截图顺序为卖单、买单；时间悬停提供毫秒及成交编号，原单格悬停提供编号、原价、原量、累计成交及撤余状态。数量默认按手显示，1手=100股，零股保留小数，可切回股。

例如买方300股连续对应三张各100股卖单，买单列合并成一个“3”手的高格子，卖单列分成三个“1”手格子；成交列每行仍为1手。卖单也按相同规则独立合并。只合并时间顺序中相邻的同号单，不为了凑一个格子重排成交；同一原单中间隔了其他原单时分段显示。格内数量是原始委托量，成交列是实际成交量。长格子在当前可见部分显示数字，避免数量落在屏幕外。

只按可确认的买卖原单编号关联，不按相同价格或时间猜配对。对手编号缺失、重复或歧义时原单格显示“—”，实际成交仍保留。撤单不画成成交；关闭“显示已撤销”时隐藏关联到已确认撤单的成交。未成交没有实际成交记录，因此“显示未成交”只作用于原单列表，不在成交还原中伪造零量记录。

每页最多300条成交，跨页继续显示该原单，避免巨大的合并表格阻塞UI。“全部成交”可解除原单定位。改变回放、切证券／日期／来源会更新或清理旧还原内容，详细匹配不再创建弹窗。

## 分钟归属、颜色及截止时间

每张原单按**提交时间**归入北京时间`[HH:mm:00, 下一分钟)`，按原始整单金额分档，不将成交发生时间当成提交时间。盘前竞价原单不挪到09:30；没有对应图表分钟的位置不绘。五日及1分钟K按图中各日分别加载和计算，不跨日拼原单编号。其他K线周期暂不聚合这些标记。

分钟卡片显示九档买卖金额／笔数，半透明、不接收鼠标事件，放在光标对侧，较小画面自动紧凑显示。量柱颜色和卡片／资金表采用同一档位配色；同时出现两档就画两个不同色方块，不猜主力身份。没有缓存或分页未齐时浮层显示原因，不发布金额；所选档位没有原单时在图下提示，成功后显示标记分钟数。

**筛选状态以当前分析截止时点为准。** 例如全日分析时，09:31的原单在下午撤销，排除撤单就会从09:31统计中剔除；这不是09:31当时已知的结果。要看历史时点状态，先用工作台“按时点回放”，再查看该时点及此前分钟；未来原单和未来撤单不会提前参与。浮层及图表下方持续显示截止时间。未齐分页不发布分钟分档、饼图和标记；尚未发生的分钟不显示数据。

## 实现与验收

`OrderFilter`、四种状态分组及按分钟索引位于domain／application；还原与预聚合在已有后台分析任务内完成。开关只合并至多四组九档计数，分钟悬停查本地索引；同一分钟缓存浮层文本。大表仍使用虚拟模型，配对格子分页；不随鼠标重跑整日还原，不生成成千上万子控件。表格主题同时覆盖`QTableView`及其派生表，显式设定深色隔行背景、文字及选中色，修复白底白字。

Ubuntu 22.04／Python 3.10、Qt 6.11.3、PyQtGraph 0.14.0。0.10的214项及15项GUI为历史交付；0.11补充真实操作路径、只读缓存、逐日身份、连续合并与色条像素验证，结果见[最新记录](VALIDATION_MINUTE_INLINE.md)。

0.10.0 wheel构建成功；在未安装Qt的独立环境中从仓库以外目录运行核心验收，四种统计笔数、分钟与全日金额守恒及真实成交配对均通过，API账本无增加。独立可执行安装包仍待分别开发和验收。
