# 0.10委托筛选、成交配对与分钟标记

日期：2026-11-05。使用已有盘口逐笔工作台及本地原始数据，不增加自动逐笔查询。前置数据能力及队列限制见[盘口工作台](ORDER_WORKBENCH.md)。

## 使用入口

1. 打开个股及日期，点击“盘口逐笔 → 读取逐笔”，或导入对应JSON。完整委托／成交分页到齐后可用；指数不套用个股逐笔。
2. “逐笔还原”上方独立勾选“显示未成交”“显示已撤销”。列表显示原始价格及成交均价，双击原单打开买卖成交配对。
3. “资金 → 原始委托分档”或展开工作台的分档页，用“统计未成交”“统计已撤销”选择口径。三处统计视图及图表同步；还原列表的显示筛选与统计筛选独立。
4. 图表下方勾选“悬停显示分钟委托分档”，移动到分时、五日或1分钟K，显示该条时间所在分钟的买卖九档金额与笔数。
5. 勾选“量柱标记”，再选择需要的金额档位。默认选中20—50万、50—100万；该分钟买卖任意方向出现对应档位原单，就在量柱顶部画同色方块。多个档位横向并列，不同笔数不重复堆同色；放大图表可看密集区域。

首次读取是显式操作，继续遵守额度与本地缓存。切换筛选、回放、鼠标移动和档位勾选不访问HTTP。开关在当前会话中保留，尚不保存到跨启动设置。

## 未成交与撤销的定义

| 条件 | 行为 |
|---|---|
| 未成交 | 截至分析时点，累计成交股数为0 |
| 部分成交、仍挂单 | 不属于“未成交”，取消未成交勾选后仍保留 |
| 部分成交后撤销剩余 | 属于“已撤销”，由撤销开关控制整张原单 |
| 勾选统计已撤销 | 仍按整张原始价格×原始数量计一笔，不按撤掉数量或已成交量改档 |
| 两开关都关闭 | 只统计至少发生一次成交、且截至分析时点未撤销的原单；部分成交仍用整张原单金额 |
| 零／重复委托号、超量关联、无可定价原价 | 始终不进入资金分档；不能通过勾选撤单将它们纳入 |

还原列表默认显示未成交及撤单；资金统计默认包含未成交、排除撤单，保留0.9统计默认口径。金额是委托名义金额，**不是实际成交流入／流出**。全体歧义／无价计数可能与撤单重叠，不能直接相加；旧分析分解计数继续保留，便于兼容既有核对。

## 成交价格与左右合并格子

还原表的“原始价格”为申报价格，“成交均价”为真实成交额÷成交股数，显示四位小数；没有成交显示“—”。双击后，中间逐笔显示时间、实际成交价格、股数、成交编号；左列是买方原单，右列是卖方原单。

例如买方300股对应三张各100股卖单，买方合并成一个高格子，对面显示三个卖方格子。若同一对手原单有多笔成交，对手格子也合并，中间保留每笔成交。卖方作为选中原单时反向合并右列。原单格内显示其原始量和全体累计成交量；中间才是与当前所选原单发生的成交股数。

只按可确认的买卖原单编号关联，不按相同价格或时间猜配对。对手编号缺失、重复或歧义时明确标注，对已确认的真实成交仍显示原始成交记录。撤单不画成成交。显示筛选决定能选择哪些原单，不删掉所选原单真实成交的对手关系；已撤余单的对手也标明状态。

每页最多300条成交，跨页继续显示该原单，避免巨大的合并表格阻塞UI。改变回放、切证券／日期／来源会关闭旧配对窗口；关闭主窗口也会关闭它。

## 分钟归属、颜色及截止时间

每张原单按**提交时间**归入北京时间`[HH:mm:00, 下一分钟)`，并按原始整单金额分档，不将成交发生时间当成提交时间。盘前竞价原单不会为了画标记移到09:30；没有对应图表分钟的位置不绘。五日图只对已加载逐笔对应的交易日显示，不把一日逐笔复制到其余四日。其他K线周期暂不聚合这些标记。

分钟卡片显示九档买卖金额／笔数，半透明、不接收鼠标事件，放在光标对侧，避免挡住行情浮窗。量柱颜色和卡片／资金表采用同一档位配色；同时出现两档就画两个不同色方块，不猜主力身份。

**筛选状态以当前分析截止时点为准。** 例如全日分析时，09:31的原单在下午撤销，排除撤单就会从09:31统计中剔除；这不是09:31当时已知的结果。要看历史时点状态，先用工作台“按时点回放”，再查看该时点及此前分钟；未来原单和未来撤单不会提前参与。浮层及图表下方持续显示截止时间。未齐分页不发布分钟分档、饼图和标记；尚未发生的分钟不显示数据。

## 实现与验收

`OrderFilter`、四种状态分组及按分钟索引位于domain／application；还原与预聚合在已有后台分析任务内完成。开关只合并至多四组九档计数，分钟悬停查本地索引；同一分钟缓存浮层文本。大表仍使用虚拟模型，配对格子分页；不随鼠标重跑整日还原，不生成成千上万子控件。表格主题同时覆盖`QTableView`及其派生表，显式设定深色隔行背景、文字及选中色，修复白底白字。

Ubuntu 22.04／Python 3.10、Qt 6.11.3、PyQtGraph 0.14.0。**完整214项测试及原生xcb的15项逐笔GUI测试通过**，Ruff及格式检查通过。覆盖四种筛选组合、原单金额而非成交金额、已撤无价及未知事件歧义原单始终排除、分钟总和与全日一致、未来状态截断、真实成交价及缺失对手、过滤后行号正确、左右合并、300条分页、暗色隔行实际像素、同步且不重复取数、双色标记、关闭与不完整数据清理。

0.10.0 wheel构建成功；在未安装Qt的独立环境中从仓库以外目录运行核心验收，四种统计笔数、分钟与全日金额守恒及真实成交配对均通过，API账本无增加。独立可执行安装包仍待分别开发和验收。
