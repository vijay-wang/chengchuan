**最新范围（2026-11-06）：** [下一交易日双时点需求](NEXT_DAY_FORECAST.md)为当前准则，盘后和北京时间14:35分别预测D+1、分别建模与统计；0.16已恢复并交付CPU研究流程，实测与未完成项见[CPU验证记录](CPU_NEXT_DAY_FORECAST.md)。下文H2及2026-11-03边界示例属于0.3历史协议，保留用于解释既有结果，不是新增两日预测需求。

方案日期：2026-11-03。实施更新：2026-11-04，**逐日诊断回放已实现并实际运行；完整独立封存验证尚未完成**。

本方案细化[量价联合预测设计](SHORT_HORIZON_FORECAST.md)的F2验证流程。0.3已实现过去视图隔离、成熟标签训练、先保存预测后评价、A/B/C及同样本基线、严格目标上界和审计导出。实际三股结果与未完成项见[验证记录](VALIDATION_FORECAST.md)；本文仍保留完整验收目标，不能将工程诊断等同于全部通过。

## 1. 用户方法与采用的验证组合

用户提出：选一个历史交易日D，只用截至D的信息预测D+1，再与已知的D+1真实行情比较；所有目标日期早于本次评估截止日期。

采用这一思路，并分为四种用途：

| 方式 | 用途 | 能说明什么 |
|---|---|---|
| 指定D的历史回放 | 核对某一天的输入、预测和真实结果 | 验证流程与个案，不估计整体准确率 |
| 连续日期滚动样本外验证 | 按时间顺序对一系列D产生预测，再统一对照 | 主要历史性能评估 |
| 最后封存测试期 | 在未参与模型选择的日期区间一次性检验冻结模型 | 检查开发和调参后的泛化表现 |
| 前瞻记录 | 从功能启用日起先保存预测，未来再评价 | 检查真实数据时效与未知行情中的表现 |

已有历史数据就能开始小规模流程验证，不必等Level-2或完整多年数据库。可先核对久立，再扩展到事先选定的多股票与不同市场环境。当前约320条日线还需扣除历史回看、训练和验证区间，不能全部当作独立测试样本。

## 2. 日期边界与交易日历

将本次评估上界记为B。按用户本次要求，B为2026-11-03，采取严格小于关系：

- H1有效：D之后第一个交易日早于B，并已有有效真实结果。
- H2有效：D之后第二个交易日早于B，并已有有效真实结果。
- D、D+1、D+2均通过市场交易日历确定，不是自然日加1或加2。
- 个股停牌、缺失、公司行为口径不明等目标，按专项规则记录不可评价原因，不顺延到别的成交日、不填零。

以相应市场日历确认后的日期为例，下面仅演示边界，不包含预测结论：

| 预测基准日D | H1目标日 | H1能否纳入本次验证 | H2目标日 | H2能否纳入本次验证 |
|---|---|---|---|---|
| 2026-10-28 | 2026-10-29 | 可以，若结果有效 | 2026-10-30 | 可以，若结果有效 |
| 2026-10-29 | 2026-10-30 | 可以，若结果有效 | 2026-11-02 | 可以，若结果有效 |
| 2026-10-30 | 2026-11-02 | 可以，若结果有效 | 2026-11-03 | 排除，目标未早于B |
| 2026-11-02 | 2026-11-03 | 排除，目标未早于B | 2026-11-04 | 排除，目标未早于B |

以后若采用“截至某日已确认收盘”的包含式上界，必须另行配置并展示，不静默改变本次严格早于B的规则。

## 3. 在D日真正能使用哪些信息

### 特征和模型都要限制

只把图表截到D还不够。以下项目都只能由D时点可知信息决定：

- 行情特征、成交量基线、高低位、行业／大盘信息、公告与阶段判断。
- 训练标签：其目标行情及必要数据必须在模拟训练截止点已经成熟并可得。
- 缺失填补、标准化、异常处理、特征筛选、参数、方向阈值及概率校准。
- 若模型按预先设定的节奏更新，只能读取当时已经成熟的过去结果。

不能先用全部历史训练，再把D之后的输入行隐藏，称为D日样本外预测。“洗盘”标签也不能在看过后续上涨后补入D日输入。

### 隔离与可核查性

0.3预测侧只接收截至D的历史视图；D+1／D+2的真实行情与标签由评价侧单独持有。即使离线程序已经下载完整数据，预测函数也不能取得未来行或标签列。测试会改变D之后的行情并比较D的特征、模型和预测是否完全一致。

历史模拟截止时间与本次实际执行时间分别记录。例如今天运行10月28日的模拟，实际执行时间是今天，特征和训练的逻辑截止点仍是10月28日；不能混淆两个时钟。

### 历史重建与当时档案分开

现在取得的历史日线可以用于回溯验证，但可能含后来的修订或价格调整。应标明“历史重建数据”；有当时保存的版本时，另标为“当时档案数据”。两者不能混报为完全一致的历史信息复现。

缺少历史公布时点、股本或公司行为资料时，按预先规定的覆盖范围处理，不用当前值回填历史。新闻／大模型分析若以后加入，也需独立控制材料时间和模型可能知道的未来信息；核心回测优先使用可复算程序，不能让已经看到后续走势的叙事分析充当盲测结果。

## 4. 一次滚动验证的执行流程

1. **登记实验。** 固定证券范围、日期范围B、H1／H2目标、数据版本、输入特征、候选模型、阈值、调参预算、更新频率和评价指标。
2. **划分开发、校准／验证与最终测试。** 按交易日期分组，保持同一天的所有股票在同一时间分区，不随机打散相邻日期。
3. **从首个可评价D开始。** 检查历史回看、日K完成状态及该目标的标签是否满足边界；不满足也留记录。
4. **取得截至D的历史视图。** 根据已登记方案选用此前固定模型，或仅用当时已成熟标签重新训练；预处理与校准同样受时间边界限制。
5. **先保存预测。** 固定原始输出、方向、模型和特征版本、截止点、输入摘要、缺失与不预测原因，再允许评价侧读取真实结果。
6. **单独揭晓真实结果。** 按既定目标计算收益和真实方向，与已保存预测对照，追加评价记录，不改写预测。
7. **D前进一个交易日。** 重复直到该目标最后一个有效D。不能挑选预测成功的日期，也不能事后跳过失败记录。
8. **统一汇总。** H1和H2分开，按股票、月份／年份、市场环境、预测类别与覆盖情况统计；与基线及A/B/C比较。

“样本外”针对产生该条预测的模型：它在发出预测时尚未使用该目标结果。滚动模型可以按事先固定的规则，在未来标签成熟后用于更晚日期的训练；不能根据测试好坏临时决定更新节奏。

## 5. 模型冻结、滚动更新与封存测试

先测固定规则或简单基线，再验证需要训练的模型。现有“吸筹／洗盘／拉升”阶段标签本身不是上涨／下跌预测；需要事先明确方向输出和不预测条件，不能对照真实涨跌后才解释标签的方向。

两种更新策略分别记录：

- **固定模型：** 测试区间入口前完成训练和校准，整个区间不更新，用于首版最终封存检验。
- **滚动模型：** 按预先规定的频率、扩展窗口或固定长度窗口训练，逐条审计可用标签，反映未来在线更新方式。

调参、阈值选择及校准使用更早的时间区间，最终封存区间不参与这些选择。看过封存结果后再修改方案，则该区间转为开发材料，新版本需要新的未参与选择的检验。

预测两交易日目标时，时间分区边缘必须清理尚未成熟或跨入下一分区的标签；本项目先按交易日期组清理，再精确检查标签可用时刻。多股票面板中的“两行”不等于“两天”，不能直接以行数代替市场日历跨度。

已经反复研究并据此调整规则的久立历史片段，应标记为开发／诊断样本，不能重新命名为未见过的封存测试。小规模诊断仍有价值，不能与最终准确率混报。

## 6. 逐条预测与评价账本

每条记录的唯一性包含实验、证券、D、目标跨度和预测版本。预测与评价分开保存并关联，批量任务可续跑，不因重复执行而重复计数。

| 信息组 | 必备内容 |
|---|---|
| 实验 | 实验标识、方案版本、登记时间、证券／日期范围、更新策略 |
| 时点 | 模拟D及截止时刻、实际执行时间、目标日期、训练标签最大可用时点 |
| 数据 | 数据内容版本、来源、历史重建／当时档案标记、输入摘要及质量状态 |
| 方法 | 特征、阶段、模型、预处理、方向阈值和校准版本 |
| 预测 | 上涨／不变／下跌或不预测、原因、原始评分或实验概率、概率类型 |
| 评价 | 标签取得时点、目标实际收益／方向、是否命中、不可评价原因 |

内部实验可保存明确标记为未校准的原始概率，用于评分和校准研究；这不等于启用面向用户的可信上涨概率。公共预测面板仍受专项中的验证门槛控制。

计划提供的对照表列：证券、D、目标日期、预测方向、实际方向、实际收益、是否命中、缺失原因及数据／模型版本。本文不填入虚构的预测方向、真实价格或命中率。

## 7. “准确率”怎样计算

至少同时给出以下指标，H1／H2分别计算：

| 指标 | 口径 |
|---|---|
| 方向命中率 | 有预测且标签有效的记录中，预测类别等于真实类别的比例 |
| 看涨信号准确率 | 有效看涨预测中，真实上涨的比例 |
| 看跌信号准确率 | 有效看跌预测中，真实下跌的比例 |
| 输入合格率 | 原计划证券／日期机会中，符合预先规定输入条件的比例 |
| 预测覆盖率 | 符合预先规定输入条件的机会中，实际给出方向预测的比例 |
| 标签可评价率 | 同一机会集合中，目标标签有效且符合边界的比例 |
| 实际类别分布 | 上涨／不变／下跌的数量与比例，不能把所有市场都假定为各半 |
| 概率质量 | Brier分数、对数损失及分组校准频率，区分辨别能力与校准 |
| 收益相关 | 各预测类别下的收益分布；另做可交易收益评估 |

不预测、缺失或失败不得当作正确，不得无痕删除。高命中率但极低覆盖率的模型，必须显示这一取舍。分母为零时标记不可计算。

主目标仍按正收益／零收益／负收益区分；中性波动带为另一个目标版本，阈值在验证阶段固定。输出完整混淆矩阵，检查模型是否只擅长多数类别。

需要的简单基线包括：恒定预测上涨、只根据训练期多数类别预测、沿用上一交易日方向。若评价收益／价格点预测，再加零收益／价格不变基线；不能用整个测试期的多数类别事先指导可部署基线。

量价特征与阶段模型按专项A/B/C做增量对照，使用公共有效样本比较，同时报告完整测试范围的覆盖。不能只将命中率与50%比较，也不能把选出少量“好样本”的比例当成全部机会的准确率。

按日期分块估计不确定性，考虑两日目标重叠和多股票共同涨跌；报告样本数及误差范围，避免把几百个高度相关记录当作同等数量的独立证据。概率校准另看分组实际频率，Brier改善本身不证明概率已校准。

收盘价方向正确不等于可交易盈利。成本、真实成交价、交收约束和无法成交的涨跌停等情况，按独立策略协议评估，不混入方向命中率定义。

## 8. 前瞻验证

在历史协议和模型冻结后，从实际启用日起按固定截止点保存预测、输入版本和生成时间；未来结果未出现时不展示标签，成熟后再追加评价。

该阶段不自动下单。其价值是检查接口延迟、日K完成状态、数据修订、模型适用范围，以及面对真正未知结果的表现。前瞻阶段同样可以采用预先登记的固定或滚动更新策略。

## 9. 分步实施与验收

用户已随后授权开发。0.3完成下面第1、2项及三股A/B/C工程诊断，第3、4项的完整封存与概率门槛仍未完成：

1. 用已有快照验证D截断、交易日目标映射和“先预测后对照”的记录流程，结果标记为工程诊断。
2. 冻结基线与方向输出，在连续历史日期上逐日验证，报告全部记录及覆盖。
3. 扩展多股票／时间跨度，完成A/B/C、封存期和不确定性评估。
4. 通过专项门槛后启用用户概率展示，同时启动前瞻记录。

完整验收需要覆盖的关键行为（0.3实际通过项见[验证记录](VALIDATION_FORECAST.md)）：

- 修改或追加D之后的行情，不改变已经生成的D预测；只影响对应评价或更晚时点合法使用的数据。
- 更换真实标签或先揭晓结果，不能改变已保存预测、特征或模型选择。
- H1／H2按严格上界过滤；上述10月30日的H2和11月2日的H1均不能误纳入本次样本。
- 训练、预处理、阈值和校准均无越界；停牌、缺失和失败记录可追溯。
- 批量续跑不重复计数，已保存预测不覆盖；同一数据和版本可复算。
- 不预测和低覆盖透明展示；负面结果及模型退化同样保留。
- GUI只在揭晓／评价视图显示未来结果，历史预测视图停在D；切股和切时点不出现旧结果覆盖。

## 10. 方法依据

- [Forecasting: Principles and Practice，时间序列交叉验证](https://otexts.com/fpp3/toolbox.html#time-series-cross-validation)：滚动预测起点，训练只使用预测目标之前的数据。
- [scikit-learn TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)：按时间切分及间隔机制；本项目股票面板还需按交易日期和标签成熟度处理，文档引用不代表已引入该依赖。
- [scikit-learn 概率校准](https://scikit-learn.org/stable/modules/calibration.html)：概率含义与校准评估；回测中的训练／校准切分仍须遵守时间边界。

这些方法帮助设计可信验证，不提供本项目的实测命中率或收益保证。
