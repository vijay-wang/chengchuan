# 启动恢复、默认无选区与图表边缘补数 · 0.14.1

日期：2026-11-05。针对“重新打开恢复上次个股最新日期、默认不选区、缩小时以相邻日期填充两侧”的交付。

## 操作与边界

1. 正常退出会保存最近成功打开的个股和周期。下次启动默认打开该股的**最新可用数据**，不恢复上次历史日期、缩放窗口或选区；最后看的是指数时仍保留此前个股。旧工作区只有`symbol/interval`也可读取，损坏代码回退默认股。命令行显式`--symbol/--interval/--dataset`仍优先，离线仅使用已保存数据。
2. 打开股票、切换日期／周期、导入快照，默认**没有选区，也不自动做区间分析**。按住Ctrl拖动才创建选区；同股刷新及补入历史时，已有手动选区按原日期保留。Esc清除后刷新不会重新生成默认选区。
3. 在价格图或成交量图上缩小、拖动至数据边缘，会自动补充相邻交易日。初次打开仍按“单日分时／最近五日／分钟K”的默认窗口显示；缩小后可继续看到更早日期。历史图向右补到较新、已发布日期时，日期导航及历史截止日随实际数据更新，自动刷新继续暂停。返回最新仍使用原按钮。

价格与量柱横轴同步，前插历史不会把原来的日期窗口移走；VWAP和涨跌幅采用各日原有参考，不将单日分时复制成其他日期。周月季年按所属周期去重，更新未完成周期不会多画一根同周／同月K线。

到最新记录、上市／数据起点、尚未发布或接口覆盖边界时，图表贴合已取得数据；不补造未来、停牌或缺失行情。腾讯源和本地导入只能浏览自身已取得范围，动态补数需要支持日期查询的猫爪源。整个图表达到50000条时提示切换较长周期。

## 性能与稳定性

- 沿用现有行情服务、交易日历和日期缓存，按已有契约选择服务。历史分钟明确传交易日，股票／指数用各自历史操作；没有增加全市场扫描。核对猫头鹰目录1.0.52，股票及指数历史分钟契约版本1.0.48。
- 手势结束后180毫秒防抖，同一时刻仅一个补数任务；一次手势最多4页。分时补页复用五日数据，每页最多约5个市场交易日。日／周／月／季／年按相应跨度补取已有日线并复用聚合。
- 常规范围适配、悬停、程序定位及重绘不请求补数。数据请求在后台运行；切股、切周期、换源、导入或关闭会取消并拦截旧结果，缩回已加载范围也会取消待返回的补页。
- 有效边界在本次浏览中记忆，避免滚动反复查询同一边界；失败页在下次新手势可重试，不自动无限重试。任务120秒上限，失败保留原图；同股刷新合并并保留已加载历史。
- 补数只扩展当前视图，不把多日合并数据写回普通单日／五日行情缓存；重新打开仍展示最新默认窗口。逐笔功能继续采用原有逐日关联与加载规则，扩展很多天时会增加所需逐笔数据量。
